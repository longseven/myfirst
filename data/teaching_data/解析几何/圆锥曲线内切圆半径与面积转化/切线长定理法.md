# 切线长定理法

## 适用场景

**适用**：题干强调切点、切线段相等，或涉及从同一点引两条切线的长度关系

**不适用**：无明确切点描述或圆外点未给出时（如仅知圆心与三角形顶点）

## 标准教学流程（步骤化）

1. 步骤1：审题定位——找出圆外三点（如△ABC顶点）及对应切点（如AQ、BQ、CQ）
2. 步骤2：选法决策——当题干出现'切线长相等'或'从P向圆引两切线'时必选
3. 步骤3：构造辅助元素——连接圆心O与各切点，形成三个直角三角形（HL全等）
4. 步骤4：逻辑闭环——写出切线长等式（如AQ = AP, BQ = BP, CQ = CP），联立解边长关系

## 关键技巧清单

- ✅ 定理：'从圆外一点引两条切线，切线长相等'（HL全等可证）
- ✅ 关系式：设切点分边为x,y,z，则a = y+z, b = x+z, c = x+y

## 核心公式

- $AQ = AP$
- $BQ = BP$
- $CQ = CP$

## 常见易错点

- ❌ 未验证切点存在性直接列等式→导致方程无解（扣1分）
- ❌ 混淆切线长与弦长（如将AQ误作AQ边）→几何关系错误（扣2分）

## 评分要点（高考阅卷标准）

- 评分点1（正确标注切点并写出一组切线长相等式 → 1分）
- 评分点2（建立三组等式并消元得边长关系 → 2分）
- 评分点3（结合三角形条件解出具体值 → 2分）
