# 余弦定理

## 适用场景

**适用**：题目给出三边关系或可推导出边的关系式（如$a^2 = b^2 + c^2 - bc$），需判断锐角/直角/钝角三角形

**不适用**：当题目仅给出角度关系（如$\tan A + \tan B + \tan C = \tan A \tan B \tan C$）且无边长信息时，余弦定理无法直接应用

## 标准教学流程（步骤化）

1. 步骤1：审题定位——将已知等式变形为$\cos A = \cdots$、$\cos B = \cdots$等形式
2. 步骤2：选法决策——若等式含$a^2,b^2,c^2$，直接对比余弦定理标准形式$\cos A = \frac{b^2 + c^2 - a^2}{2bc}$
3. 步骤3：构造辅助元素——计算$\cos A$值：若$\cos A = 0$则直角；若$\cos A > 0$则锐角；若$\cos A < 0$则钝角
4. 步骤4：逻辑闭环——结合三角形内角和为180°，判断是否等腰（如$\cos A = \cos B$推出$A=B$）或等边

## 关键技巧清单

- ✅ 技巧1：直角判定口诀——‘平方和等于平方差，直角就在大边对’，即若$a^2 = b^2 + c^2$，则∠A=90°
- ✅ 技巧2：钝角判定——若$a^2 > b^2 + c^2$，则∠A为钝角；若$a^2 < b^2 + c^2$，则∠A为锐角

## 核心公式

- $\cos A = \frac{b^2 + c^2 - a^2}{2bc}$
- $a^2 = b^2 + c^2 \iff \angle A = 90^\circ$

## 常见易错点

- ❌ 易错点1：未区分最大边即默认c为最大边，导致直角判断错误（如实际a最大却验$c^2$）→ 扣2分
- ❌ 易错点2：将$\cos A = \frac{1}{2}$直接判定为等边三角形，忽略还需验证另两角 → 扣1分

## 评分要点（高考阅卷标准）

- 评分点1（如：正确将已知式变形为余弦表达式 → 2分）
- 评分点2（如：准确计算$\cos A$值并判断角类型 → 2分）
- 评分点3（如：综合三个角得出完整形状结论（如等腰直角） → 2分）
