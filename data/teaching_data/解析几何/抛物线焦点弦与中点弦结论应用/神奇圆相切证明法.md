# 神奇圆相切证明法

## 适用场景

**适用**：证明以焦点弦AB为直径的圆与准线相切，或以AF为直径的圆与y轴相切

**不适用**：题目仅求长度或面积，未涉及圆与线位置关系时

## 标准教学流程（步骤化）

1. 步骤1：审题定位——明确圆直径（AB或AF）及目标直线（准线x=−p/2或y轴）
2. 步骤2：选法决策——计算圆心到直线距离d，证明d等于半径r
3. 步骤3：构造辅助元素——设A(x₁,y₁),B(x₂,y₂)，圆心G为AB中点，坐标$(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2})$
4. 步骤4：逻辑闭环——计算$d = |x_G + \frac{p}{2}|$，利用焦点弦公式证$d = \frac{|AB|}{2} = r$

## 关键技巧清单

- ✅ 核心等式：圆心到准线距离$d = \frac{x_1+x_2}{2} + \frac{p}{2} = \frac{x_1+x_2+p}{2} = \frac{|AB|}{2}$
- ✅ 口诀：'直径焦点弦，圆心到准线；距离算出来，恰是半径半'

## 核心公式

- $d = \frac{x_1+x_2}{2} + \frac{p}{2}$
- $|AB| = x_1 + x_2 + p$

## 常见易错点

- ❌ 圆心横坐标计算漏除2（如写成x₁+x₂）→d表达式错误（扣2分）
- ❌ 未用焦点弦公式关联x₁+x₂+p与|AB|→无法证d=r（扣3分）

## 评分要点（高考阅卷标准）

- 评分点1（正确写出圆心坐标 → 1分）
- 评分点2（距离d表达式正确（如$d = \frac{x_1+x_2}{2} + \frac{p}{2}$） → 2分）
- 评分点3（完成$d = \frac{|AB|}{2}$的等式证明 → 2分）
