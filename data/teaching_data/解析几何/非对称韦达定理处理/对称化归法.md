# 对称化归法

## 适用场景

**适用**：目标式含x₁,x₂的非对称组合（如x₁/x₂、2x₁+x₂），且已知x₁+x₂、x₁x₂

**不适用**：目标式可直接用韦达定理表示（如x₁+x₂、x₁x₂）或需几何构造时

## 标准教学流程（步骤化）

1. 步骤1：审题定位——识别目标式为非对称结构（系数不等/位置不对称）
2. 步骤2：选法决策——根据目标式类型选择对称化策略：比值型→平方和除积；系数不等型→凑等系数；分式型→做商找关系
3. 步骤3：构造辅助元素——写出对称韦达式（S=x₁+x₂,C=x₁x₂），建立目标式与S、C的等式
4. 步骤4：逻辑闭环——解出目标式数值或表达式，验证特殊值（如x₁=2,x₂=-2）确保正确

## 关键技巧清单

- ✅ 比值型口诀：'x₁/x₂ + x₂/x₁ = (x₁+x₂)²/(x₁x₂) - 2'
- ✅ 系数不等型口诀：'2x₁+x₂ = (x₁+x₂) + x₁ → 构造x₁ = (2x₁+x₂) - (x₁+x₂)'

## 核心公式

- $\frac{y_1 + a}{y_2 + b} = \frac{S + a}{S + b} \cdot \frac{1}{1 + \frac{b-a}{S}}$
- $\frac{x_1}{x_2} + \frac{x_2}{x_1} = \frac{(x_1 + x_2)^2}{x_1 x_2} - 2$

## 常见易错点

- ❌ 未验证特殊值→计算得x₁/x₂=4但x₁=1,x₂=2时比值为1/2→未发现符号错误→扣2分
- ❌ 混淆分子分母→分式型中误将(y₁+3)/(y₂-1)当作对称式直接套用韦达→全题0分

## 评分要点（高考阅卷标准）

- 评分点1（如：识别非对称结构并选择对称化策略 → 1分）
- 评分点2（如：写出(x₁+x₂)²/(x₁x₂) = -2/3λ → 2分）
- 评分点3（如：解得λ²=1 → 2分）
- 评分点4（如：代入得定值1/3 → 3分）
