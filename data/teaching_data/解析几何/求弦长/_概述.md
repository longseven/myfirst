# 求弦长

**难度**: 中档

## 1. 常见出题形式

- 已知直线与圆锥曲线相交，求弦长（固定直线→直接代入公式）
- 动直线（含参数k/m）与圆锥曲线相交，求弦长最值
- 两动直线（如垂直）与同一圆锥曲线相交，求弦长倒数和/积为定值
- 直线与圆相交，求被截得的弦长（如2017全国卷：直线x−y−2=0与圆(x−1)²+y²=1相交，求弦长）
- 含参直线与定圆相交，已知弦长求参数（如直线x−y+m=0被圆截得弦长为m，求m）
- 过定点的动直线与圆相交，求弦长的最值（如过点P(1,2)的直线与圆(x−3)²+y²=9相交，求弦长最小值）
- 固定直线与圆锥曲线相交的弦长（直接代入公式）
- 动直线（含参数k/m）与圆锥曲线相交的弦长最值
- 两动弦（如垂直焦点弦）的弦长倒数和为定值
- 过定点T的两条直线交曲线于A,B和P,Q，已知TA·TB=TP·TQ，求斜率关系
- 直线交抛物线于A,B，交椭圆于C,D，已知AC=BD，求直线斜率
- 已知PA⊥PB（P在抛物线上，A,B为定点），求PA·PB最值
- 直线与圆相交，求被截得的弦长（如：直线L被圆C截得的线段长度）
- 含参直线与定圆相交，已知弦长求参数（如：直线x−y+m=0被圆截得弦长为m，求m）
- 过定点的动直线与定圆相交，求弦长的最值（如：过点P的直线被圆截得弦长的最大值与最小值）
- 焦点弦长（过焦点的弦，如2019新课标Ⅲ卷△MF₁F₂等腰）
- 中点弦长（已知中点求弦长，如2013新课标Ⅰ卷）
- 倾斜角已知的弦长（如2021浙江学业考试中∠F₁PF₂=90°）
- 焦点弦长（过焦点的弦）——已知端点横坐标或倾斜角
- 一般弦长——联立韦达后用$\sqrt{1+k^2}\cdot|x_1-x_2|$
- 隐含弦长——通过圆幂定理（$TA\cdot TB=TC\cdot TD$）反推弦长关系

## 2. 推荐解题方法及适用场景

| 方法 | 适用场景 | 不适用场景 |
|--------|------------|--------------|
| **联立韦达** | 直线与圆锥曲线联立后可得一元二次方程，且目标为弦长或其函数（如1/|AB|+1/|CD|）时 | 当直线斜率不存在（竖直）且未单独讨论，或联立后方程退化（Δ=0）时 |
| **垂径定理+勾股定理** | 题干明确给出直线与圆方程（或可快速化为标准式），且所求为具体弦长数值或含参弦长表达式 | 题干未给直线方程、仅给几何条件（如‘过定点’‘与某线垂直’）且需先构造直线；或要求弦长范围/最值但无法识别定点时 |
| **定点识别+几何最值** | 直线含参数（如y=kx+b中k变动）且隐含过定点，或题干直接给出‘过定点P’条件，求弦长最值 | 直线为定直线无参数；或定点在圆外/圆上导致垂径不适用（如定点在圆外时弦长无最小值） |
| **弦长转化法** | 弦的两端点不在同一曲线上（如AC中A在抛物线、C在椭圆），或直接计算复杂 | 两端点在同一圆锥曲线上且题目明确要求'用弦长公式'时，应直接使用√[(1+k²)·Δ/a²] |
| **焦半径公式** | 题干明确涉及椭圆/双曲线上点到焦点的距离，且已知点横坐标或可求横坐标 | 当点坐标未知且无法通过其他条件解出x₀（如仅知角度关系）时，需转向焦点三角形面积法 |
| **焦点弦公式法** | 题目明确‘过焦点F的弦AB’且给出倾斜角φ或端点横坐标时 | 弦不过焦点时禁用（如中点弦、平行弦），否则公式失效 |
