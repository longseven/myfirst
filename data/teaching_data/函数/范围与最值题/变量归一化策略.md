# 变量归一化策略

## 适用场景

**适用**：目标式含多个变量（a,b,c,A,B,C），但存在约束条件（如固定一角、固定一边、三角形内角和）

**不适用**：无任何约束的自由变量最值（高中不考）或约束无法消元（需拉格朗日乘数法）

## 标准教学流程（步骤化）

1. 步骤1：审题定位——找出所有约束：固定角（如B=60°）、固定边（如b=√3）、内角和A+B+C=π
2. 步骤2：选法决策——若目标式对称（a,c系数相同），优先用余弦定理+基本不等式；若不对称（2a+c），必转角：用正弦定理a=2RsinA等转化为单角函数
3. 步骤3：构造辅助元素——引入辅助角（如k·sinA + m·cosA = √(k²+m²)·sin(A+φ)）或换元（令t=a/b）
4. 步骤4：逻辑闭环——求导或三角函数性质确定极值点，并验证端点是否可取（开闭区间）

## 关键技巧清单

- ✅ 技巧1：'对称用余弦，不对称转角'——对称结构用余弦定理得a²+c²-ac类式，再用a²+c²≥2ac；非对称必用a=2R·sinA转化为角函数
- ✅ 技巧2：辅助角公式——$k\sin x + m\cos x = \sqrt{k^2+m^2}\sin(x+\varphi)$，其中$\tan\varphi = m/k$

## 核心公式

- $a = 2R\sin A$
- $k\sin x + m\cos x \leq \sqrt{k^2 + m^2}$

## 常见易错点

- ❌ 易错点1：锐角三角形未限制所有角——只写0<A<π/2，漏写0<C<π/2且C=π−A−B，导致定义域错误，高考扣2分
- ❌ 易错点2：端点值未验证可取性——如A∈(30°,90°)时最小值在A→30°⁺取得，但写成闭区间[4,2√7]，高考扣1分

## 评分要点（高考阅卷标准）

- 评分点1（如：正确写出角约束A+C=120° → 1分）
- 评分点2（如：用正弦定理转化为4sinA+2sinC → 2分）
- 评分点3（如：合并为辅助角形式并给出最大值 → 2分）
