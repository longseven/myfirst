# 二面角余弦定理法

## 适用场景

**适用**：当两面夹角θ已知（θ∈(0°,180°)），且交线AC可表示为θ函数时（如等腰三角形中设顶角为2α）

**不适用**：当二面角θ无法确定或交线AC与θ无关时

## 标准教学流程（步骤化）

1. 步骤1：审题定位——识别两面（如△ABC与△PAC）及二面角θ，确认交线AC
2. 步骤2：选法决策——设AC = L，用三角换元（如L = 2a\sin\alpha）；分别求两面外接圆半径r₁、r₂及圆心到AC距离m、n
3. 步骤3：构造辅助元素——在四边形O₁GO₂中，∠O₁GO₂ = θ，O₁G = m，O₂G = n，用余弦定理求O₁O₂，再用正弦定理求外接圆直径OG
4. 步骤4：逻辑闭环——代入$R^2 = OG^2 + (L/2)^2$，化简为关于α的函数，求最值（常用AM-GM或导数）

## 关键技巧清单

- ✅ 二面角模型通式：$R^2 = \frac{m^2 + n^2 - 2mn\cos\theta}{\sin^2\theta} + \frac{L^2}{4}$
- ✅ 三角换元口诀：等腰三角形底边→设顶角2α，L = 2a\sin\alpha；直角三角形斜边→L = 2r

## 核心公式

- $R^2 = \frac{m^2 + n^2 - 2mn\cos\theta}{\sin^2\theta} + \frac{L^2}{4}$
- $L = 2a\sin\alpha$

## 常见易错点

- ❌ 混淆二面角θ与设角α（如将θ=30°误代入α）→ 公式全错，0分
- ❌ 求最值时忽略定义域（如cos⁴α = 1/3需验证α∈(0,π/2)）→ 扣1分

## 评分要点（高考阅卷标准）

- 评分点1（如：正确三角换元并表示L、r₁、r₂ → 2分）
- 评分点2（如：推导出$R^2$关于α的表达式 → 3分）
- 评分点3（如：求出最小值并写出表面积$4\pi R^2$ → 2分）
