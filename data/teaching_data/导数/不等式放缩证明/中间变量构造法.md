# 中间变量构造法

## 适用场景

**适用**：不等式两端为不同类函数（如e^x与lnx、幂函数与对数）直接比较困难时

**不适用**：两端为同类函数（如两个二次函数）或可直接求导判断单调性时

## 标准教学流程（步骤化）

1. 步骤1：审题定位——识别A与B的函数类型差异，确定需引入中间量C
2. 步骤2：选法决策——根据A/B类型选择基础放缩（e^x≥x+1；lnx≤x−1）或进阶放缩（e^x≥1+x+x²/2；飘带不等式）
3. 步骤3：构造辅助元素——将A放缩为C（A≤C或A≥C），B放缩为C（C≤B或C≥B）
4. 步骤4：逻辑闭环——写出A≤C≤B（或A≥C≥B）→传递得证

## 关键技巧清单

- ✅ 基础放缩四式：'$e^x \geq x+1$'、'$e^x \geq ex$'、'$\ln x \leq x-1$'、'$\ln x \leq \frac{x}{e}$'
- ✅ 飘带不等式：'$\frac{2(x-1)}{x+1} \leq \ln x \leq \frac{x-1}{2} + \frac{x-1}{2x}$（x>0）'

## 核心公式

- $e^x \geq 1+x+\frac{x^2}{2}$
- $\frac{2(x-1)}{x+1} \leq \ln x$
- $\ln x \leq x-1$

## 常见易错点

- ❌ 直接使用未证明的放缩式（如未证e^x≥x+1就使用）→高考扣2分
- ❌ 放缩方向错误（如用lnx≤x−1去放大lnx导致不等号反向）→全题0分

## 评分要点（高考阅卷标准）

- 评分点1（正确写出所用放缩不等式 → 1分）
- 评分点2（完成至少一次有效放缩并注明方向（≥/≤） → 2分）
- 评分点3（中间变量C与A、B的不等关系均正确 → 2分）
- 评分点4（最终不等式传递链完整 → 1分）
