# 边角化简

**难度**: 中档

## 1. 常见出题形式

- 给定含边与角的齐次等式（如 $2b\sin A = a\sin B$），求某边、某角或三角形形状
- 含正弦倍角/平方/和差的边角混合式（如 $\sin^2 A = \sin B \sin C$ 或 $\sin(B+C) = \sin A + \cos A \cos C$），求角或范围
- 多条件联立化简（如已知 $\frac{a}{\sin A} = 2$ 且 $\cos 2C - \cos 2B = \frac{b^2 - c^2}{bc}$），求特定角

## 2. 推荐解题方法及适用场景

| 方法 | 适用场景 | 不适用场景 |
|--------|------------|--------------|
| **正弦定理** | 等式左右两侧为齐次式（边与角的幂次一致），且含对边对角结构（如 $a$ 与 $\sin A$ 同现）或可转化为比例关系（如 $\frac{\sin A}{\sin B} = \frac{a}{b}$） | 非齐次式（如 $\sin B \sin C = \frac{2}{3}$ 左侧为角的二次式，右侧为常数，无对应边幂次）；或含非三角函数项（如含 $\tan A$ 未转化、含绝对值、分段函数） |
| **余弦定理** | 等式含边的平方项（如 $a^2, b^2+c^2$）或明确给出三边一角关系；或正弦定理化简后出现 $\cos A$ 形式需进一步求角 | 纯角关系式（如 $\sin A + \sin B = \sin C$）无边参与；或仅含一次边且无角平方（如 $a+b=c$） |
| **三角恒等变换** | 化简后式子纯为角（如 $\sin A + \sin B = \sin C$）或含倍角/和差/平方（如 $\cos 2A, \sin(B+C)$）；或三内角 $A,B,C$ 同时出现需消元 | 式子含边未完全消去；或仅单角（如 $\sin 2B = \frac{1}{2}$）无需消元 |
