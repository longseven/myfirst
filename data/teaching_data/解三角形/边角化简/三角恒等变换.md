# 三角恒等变换

## 适用场景

**适用**：化简后式子纯为角（如 $\sin A + \sin B = \sin C$）或含倍角/和差/平方（如 $\cos 2A, \sin(B+C)$）；或三内角 $A,B,C$ 同时出现需消元

**不适用**：式子含边未完全消去；或仅单角（如 $\sin 2B = \frac{1}{2}$）无需消元

## 标准教学流程（步骤化）

1. 步骤1：审题定位——确认式中仅含角 $A,B,C$ 及其三角函数，且三者均存在
2. 步骤2：选法决策——若三内角同现，必用 $A+B+C=\pi$ 消元；若含倍角/和差，选对应公式展开
3. 步骤3：构造辅助元素——将 $\sin C$ 写为 $\sin(\pi - A - B) = \sin(A+B)$，或 $\cos 2A = 1 - 2\sin^2 A$ 等
4. 步骤4：逻辑闭环——展开后合并同类项，利用 $\sin A > 0$（三角形内角）约去公因子，解出角关系

## 关键技巧清单

- ✅ 三内角消元口诀：'三内角和为 $\pi$，互补角正弦相等；$\sin C = \sin(A+B)$，$\cos C = -\cos(A+B)$'
- ✅ 倍角降幂：$\cos 2A = 1 - 2\sin^2 A$（优先用于含 $\sin^2$ 式），$\sin 2A = 2\sin A \cos A$（用于含 $\sin A \cos A$ 式）
- ✅ 和差展开：$\sin(B \pm C) = \sin B \cos C \pm \cos B \sin C$，$\cos(B \pm C) = \cos B \cos C \mp \sin B \sin C$

## 核心公式

- $\sin(A+B) = \sin A \cos B + \cos A \sin B$
- $\cos 2A = 1 - 2\sin^2 A$
- $\sin^2 A + \cos^2 A = 1$

## 常见易错点

- ❌ 忘记三角形内角限制：由 $\sin A = \sin B$ 直接得 $A = B$，未考虑 $A + B = \pi$（即 $C = 0$ 不成立）→ 扣1分
- ❌ 展开符号错误：$\sin(B - C) = \sin B \cos C + \cos B \sin C$（应为减号）→ 全过程无效
- ❌ 约零失误：由 $\sin A \cos C = 0$ 得 $\cos C = 0$ 时，未说明 $\sin A \neq 0$（因 $A \in (0,\pi)$）→ 扣1分

## 评分要点（高考阅卷标准）

- 评分点1（消元依据）：写出 $A+B+C=\pi$ 或 $\sin C = \sin(A+B)$ → 1分
- 评分点2（公式正确展开）：正确应用和差/倍角公式（如 $\sin(A+B) = \sin A \cos B + \cos A \sin B$） → 2分
- 评分点3（关键约简）：指出 $\sin A > 0$ 并据此约去 → 1分
- 评分点4（终角确定）：解出角值并验证在 $(0,\pi)$ 内 → 1分
