# 参数法（三角换元）

## 适用场景

**适用**：动点P在圆上运动，目标式为x,y的代数式，且含参直线/距离/平方和等难以几何转化的情形

**不适用**：圆为一般式未配方、或目标式含绝对值/分段函数导致三角换元后无法统一处理

## 标准教学流程（步骤化）

1. 步骤1：审题定位——将圆方程配方为标准式(x−a)²+(y−b)²=r²
2. 步骤2：选法决策——设P(a+rcosθ,b+rsinθ)，将x,y全部替换为θ的三角函数
3. 步骤3：构造辅助元素——对目标式进行三角恒等变形（如辅助角公式、降幂）
4. 步骤4：逻辑闭环——利用sinθ,cosθ∈[−1,1]确定最值，或用辅助角公式Asinθ+Bcosθ∈[−√(A²+B²),√(A²+B²)]

## 关键技巧清单

- ✅ 圆参数方程：$x = a + r\cos\theta,\ y = b + r\sin\theta$
- ✅ 辅助角公式：$A\sin\theta + B\cos\theta = \sqrt{A^2 + B^2}\sin(\theta + \varphi)$
- ✅ 平方和处理：$(a+rcos\theta)^2 + (b+rsin\theta)^2 = a^2 + b^2 + r^2 + 2ar\cos\theta + 2br\sin\theta$

## 核心公式

- $x = a + r\cos\theta$
- $y = b + r\sin\theta$
- $A\sin\theta + B\cos\theta \in [-\sqrt{A^2 + B^2},\ \sqrt{A^2 + B^2}]$

## 常见易错点

- ❌ 未将圆化为标准式直接设参数→参数错误全扣
- ❌ 换元后未化简至单一三角函数→无法判断最值扣3分

## 评分要点（高考阅卷标准）

- 评分点1（正确写出参数方程→2分）
- 评分点2（目标式化简及最值结论正确→3分）
