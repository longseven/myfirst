# 正弦定理

## 适用场景

**适用**：等式左右两侧为齐次式（边与角的幂次一致），且含对边对角结构（如 $a$ 与 $\sin A$ 同现）或可转化为比例关系（如 $\frac{\sin A}{\sin B} = \frac{a}{b}$）

**不适用**：非齐次式（如 $\sin B \sin C = \frac{2}{3}$ 左侧为角的二次式，右侧为常数，无对应边幂次）；或含非三角函数项（如含 $\tan A$ 未转化、含绝对值、分段函数）

## 标准教学流程（步骤化）

1. 步骤1：审题定位——检查等式是否为齐次式（统计所有项中边的总次数与角的三角函数总次数是否相等）
2. 步骤2：选法决策——若齐次且含 $a,\sin A$ 等对边对角，则优先用正弦定理；若含 $a^2,b^2$ 等平方项，转向余弦定理
3. 步骤3：构造辅助元素——将每条边 $a,b,c$ 替换为 $2R\sin A,2R\sin B,2R\sin C$（或反向替换），明确约去 $R$ 的可行性
4. 步骤4：逻辑闭环——化简后得到纯角或纯边关系式，结合三角恒等变换或余弦定理完成最终求解

## 关键技巧清单

- ✅ 齐次判据口诀：'边角幂次须相同，左右同次才可约；缺一不可留 $2R$，乱约必错扣1分'
- ✅ 正弦定理变形式：$a:b:c = \sin A : \sin B : \sin C$，用于判断三角形形状（如 $a=b \Rightarrow \sin A=\sin B \Rightarrow A=B$ 或 $A+B=\pi$，再结合三角形内角和排除钝角）
- ✅ 边角互化三步走：写 $a=2R\sin A$ → 代入全式 → 约 $2R$（仅当齐次）→ 得纯角/纯边式

## 核心公式

- $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$
- $a = 2R \sin A$, $b = 2R \sin B$, $c = 2R \sin C$

## 常见易错点

- ❌ 忽略齐次前提直接替换：如将 $\sin B \sin C = \frac{2}{3}$ 错误替换为 $bc = \frac{2}{3}$，导致 $R$ 未消、结果错误（高考扣2分）
- ❌ 混淆正弦定理适用条件：在非对边对角结构（如 $a$ 与 $\sin C$ 同现）强行套用，造成逻辑断裂（高考扣1分）
- ❌ 忘记三角形内角约束：由 $\sin B = \frac{1}{2}$ 得 $B=30^\circ$ 或 $150^\circ$ 后，未验证 $A+B+C=\pi$ 导致增解（高考扣1分）

## 评分要点（高考阅卷标准）

- 评分点1（齐次性验证）：指出等式为齐次式并说明理由 → 1分
- 评分点2（正弦定理代入）：正确写出 $a=2R\sin A$ 等三式或直接使用比例式 → 2分
- 评分点3（约去 $2R$）：明确写出约去过程或说明‘因齐次故 $R$ 可约’ → 1分
- 评分点4（终解验证）：结合三角形内角和或锐角/钝角条件舍去增解 → 1分
