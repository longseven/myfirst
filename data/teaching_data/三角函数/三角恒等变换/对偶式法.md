# 对偶式法

## 适用场景

**适用**：当题干明确给出形如 $a\sin\theta + b\cos\theta = c$ 的单一方程，且未提供 $\sin^2\theta + \cos^2\theta = 1$ 直接联立条件时优先使用

**不适用**：当题目已直接给出 $\sin^2\theta + \cos^2\theta = 1$ 或可轻松导出另一独立方程（如 $\sin\theta - \cos\theta$）时，不推荐；或当 $a,b$ 含复杂根式/分数导致 $A^2+B^2=C^2+X^2$ 计算量反超时

## 标准教学流程（步骤化）

1. 步骤1：审题定位——识别题干是否为单一方程 $a\sin\theta + b\cos\theta = c$，确认未知数个数与方程个数不匹配
2. 步骤2：选法决策——判断是否满足‘系数平方和=右边平方和’结构，即 $a^2+b^2=c^2+X^2$ 可解
3. 步骤3：构造辅助元素——写出对偶式 $b\sin\theta - a\cos\theta = X$（符号相反、$\sin\leftrightarrow\cos$互换）
4. 步骤4：逻辑闭环——联立原式与对偶式解二元一次方程组，结合角范围筛选有效解

## 关键技巧清单

- ✅ 技巧1：对偶式构造口诀——‘sin↔cos，+↔−’，如 $\sin\theta+2\cos\theta$ 的对偶式为 $2\sin\theta-\cos\theta$
- ✅ 技巧2：核心公式——$a^2 + b^2 = c^2 + X^2$（由两式平方相加消去交叉项导出）

## 核心公式

- $a^2 + b^2 = c^2 + X^2$
- $\sin^2\theta + \cos^2\theta = 1$

## 常见易错点

- ❌ 易错点1：忽略角范围导致多解误选——如第二象限角必须满足 $\cos\theta<0, \sin\theta>0$，未验证直接代入扣2分
- ❌ 易错点2：对偶式符号写反——将 $a\sin\theta + b\cos\theta$ 的对偶式错写为 $a\cos\theta + b\sin\theta$（未变号），导致后续全错

## 评分要点（高考阅卷标准）

- 评分点1（如：正确写出对偶式 → 1分）
- 评分点2（如：列出 $a^2+b^2=c^2+X^2$ 并解出 $X$ → 2分）
- 评分点3（如：联立求解并结合象限筛选唯一解 → 2分）
