# 变量统一法

## 适用场景

**适用**：式子含多个三角函数（如sinx、cosx混杂）且可转化为单变量时

**不适用**：含不可约三角函数组合（如sinx+cos2x）、或需保留多变量关系时

## 标准教学流程（步骤化）

1. 步骤1：审题定位——识别式子中三角函数种类及次数（如sin²x、cosx）
2. 步骤2：选法决策——选择主元：若含sin²x/cos²x→用sin²x=1−cos²x统一为cosx；若含sinx·cosx→用sin2x=2sinxcosx降次
3. 步骤3：构造辅助元素——令t=cosx（或sinx），将原式化为t的代数函数（如三次函数）
4. 步骤4：逻辑闭环——对代数函数求导/配方法/换元，求最值并回代

## 关键技巧清单

- ✅ 技巧1：sin²x=1−cos²x（降次核心）
- ✅ 技巧2：sinx·cosx=sin2x/2（乘积转单角）
- ✅ 技巧3：辅助角公式统一：asinx+bcosx=√(a²+b²)sin(x+φ)

## 核心公式

- $\sin^2 x = 1 - \cos^2 x$
- $\sin x \cos x = \frac{1}{2} \sin 2x$
- $a\sin x + b\cos x = \sqrt{a^2 + b^2} \sin(x + \varphi)$

## 常见易错点

- ❌ 易错点1：换元后未标注t∈[−1,1]导致范围错误→扣2分
- ❌ 易错点2：求导后未检验端点值（如t=±1）→漏最值扣1分

## 评分要点（高考阅卷标准）

- 评分点1（变量统一）：正确用sin²x=1−cos²x将式子化为cosx的函数 → 2分
- 评分点2（换元设定）：令t=cosx并写出t∈[−1,1] → 1分
- 评分点3（代数处理）：对三次函数求导并解临界点 → 2分
- 评分点4（最值回代）：结合t范围确定最大值并写出对应x值 → 1分
