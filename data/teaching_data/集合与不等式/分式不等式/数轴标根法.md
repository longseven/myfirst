# 数轴标根法

## 适用场景

**适用**：分式不等式右侧为0，且分子分母均可因式分解为一次因式（含重根）时

**不适用**：当分母含高次不可约因式，或右侧非零未移项化简时

## 标准教学流程（步骤化）

1. 步骤1：审题定位——确认不等式已化为 $\frac{P(x)}{Q(x)}\bowtie0$ 形式，且 $Q(x)\ne0$
2. 步骤2：选法决策——若 $P(x),Q(x)$ 均为一次因式乘积（含平方项），则用数轴标根法
3. 步骤3：构造辅助元素——求所有根（分子零点为'变号根'，分母零点为'断点'），在数轴标出并按大小排序；用'奇穿偶不穿'法则从右上方起穿线
4. 步骤4：逻辑闭环——根据不等号取线在x轴上方（$>0$）或下方（$<0$）部分；'断点'必为空心，'变号根'含等号则实心

## 关键技巧清单

- ✅ 技巧1：'奇穿偶不穿'——根的重数为奇数则穿线，偶数则反弹（如 $(x-1)^2$ 在 $x=1$ 处不穿）
- ✅ 技巧2：'断点必空心'——分母为0的点永远不取，必须标注空心点

## 核心公式

- $\frac{A(x)}{B(x)} > 0 \iff A(x)B(x) > 0 \text{ 且 } B(x) \ne 0$
- $\frac{A(x)}{B(x)} \ge 0 \iff A(x)B(x) \ge 0 \text{ 且 } B(x) \ne 0$

## 常见易错点

- ❌ 易错点1：将 $\frac{A}{B}\ge0$ 直接等价为 $A\cdot B\ge0$ 而忽略 $B\ne0$ 条件→高考扣2分
- ❌ 易错点2：对偶次重根误用'穿线'，导致区间符号错误→高考扣1分

## 评分要点（高考阅卷标准）

- 评分点1（正确标出所有根及断点 → 2分）
- 评分点2（穿线方向与奇偶性匹配 → 2分）
- 评分点3（区间取对且端点标注符合要求 → 2分）
