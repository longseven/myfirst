# 求范围最值

**难度**: 中档-拔高

## 1. 常见出题形式

- 离心率e的取值范围（椭圆/双曲线）——通过几何约束转化为a,c不等式
- 弦长|PQ|的最大值——联立后化为含k的函数，分析分式/根式最值
- 三角形面积S_△OPQ的最大值——转化为|x₁−x₂|型，再用Δ/A²构造分式函数
- 圆上动点到定点的距离最值（含内含、相离、外切等位置关系）
- 圆上动点到定直线的距离最值
- 过圆内定点的弦长最值（最长为直径，最短为垂直于该定点与圆心连线的弦）
- 两圆上各取一动点，求两点间距离的最值（需先判别圆心距与半径和/差关系）
- 椭圆上动点P到定点B（如上顶点）的距离最大值问题
- 椭圆上动点P到定直线的距离最小值问题
- 圆上动点到定点/定直线的距离最值问题（含参数圆心或半径）
- 圆上点(x,y)满足方程，求形如x−y、y/x、|2x+y−1|等代数式的最值（如2023全国乙卷：圆(x−2)²+(y−1)²=9，求x−y最大值）
- 含参直线与圆相切/相交，求参数范围（如直线x−y+m=0与圆x²+y²=4有公共点，求m范围）
- 动点P在圆上，求PA²+PB²+PC²等组合式最值（如P在x²+y²=4上，A(−1,1),B(1,1),C(−2,0)，求PA²+2PB²+3PC²最大值与最小值之和）
- 椭圆上点到焦点距离范围（如2019新课标Ⅲ卷等腰三角形问题）
- 双曲线上点到渐近线距离（如焦点到渐近线距离恒为b）
- 椭圆上动点到定点距离最值（如PB最大值）
- 椭圆上动点到定直线距离最值（如点P到y=½x-2的最小距离）
- 带系数的折线段和最值（如√3·MA+MB最小值）
- 离心率e的取值范围（椭圆0<e<1，双曲线e>1）
- 存在性条件下的参数范围（如：椭圆上存在点P使PF₁中垂线过F₂）
- 几何约束下弦长/面积/距离的最值（如：△OPQ面积最大值、PQ弦长最大值）
- 圆上动点到定点的距离最值（含内含、相离等位置关系）
- 过圆内定点的弦长最值（最长为直径，最短为垂直于该点与圆心连线的弦）
- 两圆上各取一动点，求两点间距离的最值（含内含、外离、相交等）
- 动点P在椭圆上，求PB（B为定点）的最大值
- 动点P在椭圆上，求P到定直线的距离最小值
- 圆上动点到定点/定直线的距离最值（含参数圆心运动）
- 过定点P的动直线与定圆相交，求弦长|AB|的取值范围或最值
- 圆上动点P与定点A、B构成的代数式（如|PA|²+2|PB|²）的最值
- 含参直线与圆位置关系中，求参数使弦长满足特定条件（如弦长≥某值）

## 2. 推荐解题方法及适用场景

| 方法 | 适用场景 | 不适用场景 |
|--------|------------|--------------|
| **设点法** | 当题干给出动点在曲线上且含距离、数量积、斜率等代数条件时（如‘存在点P使PF₁中垂线过F₂’） | 当条件完全由直线斜率、截距等参数主导，无明确动点坐标需求时 |
| **联立韦达** | 当问题涉及直线与圆锥曲线相交的两个交点P,Q的对称式（如x₁+x₂,x₁x₂,k₁k₂,|x₁−x₂|）时 | 当仅需求单点坐标或需精确解出P,Q坐标（如求轨迹具体点）时 |
| **几何定位法** | 所有含圆的最值问题，尤其当目标函数具有明确几何意义（距离、弦长、垂足）时优先使用 | 当目标函数无法直接对应几何量（如含向量模平方、数量积、斜率比等代数复合表达式）且无明显几何转化路径时 |
| **将军饮马转化法** | 折线路径和最短问题，且折点在定直线（如x轴、y轴、y=kx+b）上，其余端点在同侧（均在直线上方/下方） | 折点不在直线上（如在圆上、抛物线上）或端点在直线异侧时 |
| **向量中点转化法** | 圆上两点A、B满足弦长|AB|为定值，求与OA+OB、OA·OB等向量运算相关的最值 | 弦长不固定或目标非向量线性/二次型（如求∠AOB最值）时 |
| **设点消元法** | 目标函数为二次型（如距离平方、弦长平方），且约束条件为椭圆标准方程（x²/a² + y²/b² = 1）时优先使用 | 目标函数含一次项（如|x - 2y|）或根号嵌套时，直接代入将导致高次无理式，不可行 |
| **三角换元法** | 目标函数含一次项（如|x - 2y|）且约束为椭圆方程时，必须用三角换元避免无理式 | 当目标函数本身为二次型（如(x-1)²+(y-2)²）时，三角换元反而增加冗余计算 |
| **数形结合（截距/斜率/距离型）** | 目标式可转化为直线截距、斜率或点到直线距离的几何意义，且约束条件为圆方程 | 目标式含高次项（如x²y）、多变量耦合难分离，或约束非圆（如椭圆、双曲线） |
| **参数法（三角换元）** | 动点P在圆上运动，目标式为x,y的代数式，且含参直线/距离/平方和等难以几何转化的情形 | 圆为一般式未配方、或目标式含绝对值/分段函数导致三角换元后无法统一处理 |
| **焦半径公式** | 已知椭圆/双曲线标准方程，求点到焦点距离的最值、或存在性问题（如PF₂=2c）时 | 当点不在曲线上，或需结合其他几何条件（如内切圆、顶角）时 |
| **几何转化法** | 含系数的折线段（如k·PA+PB）且存在圆背景（如阿氏圆、切点弦）时 | 无几何背景、纯代数最值（如x²+y²在x+y=1下最值）时 |
| **向量转化法** | 当最值目标含向量和、数量积、模长等线性/二次结构，且存在圆上动点与定点组合时 | 当目标函数不含向量运算或动点不在圆上时禁用 |
| **几何极值法（直径与垂径）** | 题干含‘过定点’‘动直线’‘弦长最值’等关键词，且定点在圆内；或问题可转化为圆上点到定点/定直线距离极值 | 当定点在圆外或圆上，或目标函数含高次项、非对称结构（如|PA|·|PB|）时，此法失效，需转向参数法或三角换元 |
