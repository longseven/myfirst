# 底面外接圆垂线定位法

## 适用场景

**适用**：适用于任意三棱锥，尤其当某一面（如△ABC）便于求外心O₁时；是万能兜底方法

**不适用**：当底面三点共线（退化三角形）或外心无法确定（如无角度/边长信息）时

## 标准教学流程（步骤化）

1. 步骤1：审题定位——选定一个非退化面（优先选直角、等边、已知角边的面）作为底面△ABC
2. 步骤2：选法决策——计算该面外心O₁（直角三角形在斜边中点；等边三角形在重心；一般三角形用正弦定理求R再定位）
3. 步骤3：构造辅助元素——过O₁作底面垂线l；设球心O在l上，令OP = OA（P为第四个顶点），引入参数h = OO₁
4. 步骤4：逻辑闭环——列方程$OP^2 = OA^2$（即$h^2 + (O_1P)^2 = R_{\text{底}}^2$），解出h，再求$R = \sqrt{h^2 + R_{\text{底}}^2}$

## 关键技巧清单

- ✅ 正弦定理求外接圆半径：$2R = \frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$
- ✅ 垂线法核心等式：设O在过O₁的垂线上，$OA = OB = OC$自动满足，只需令$OP = OA$

## 核心公式

- $2R_{\text{底}} = \frac{a}{\sin A}$
- $R = \sqrt{h^2 + R_{\text{底}}^2}$

## 常见易错点

- ❌ 未验证O₁是否为底面外心（如将重心误作外心）→ 导致OA≠OB≠OC → 全题0分
- ❌ 列方程时混淆$OP^2$与$O_1P^2$（漏加垂线段平方）→ 扣2分

## 评分要点（高考阅卷标准）

- 评分点1（如：正确求出底面外心O₁坐标或位置 → 2分）
- 评分点2（如：设参并列出$OP^2 = OA^2$方程 → 2分）
- 评分点3（如：解出参数并计算R值 → 2分）
