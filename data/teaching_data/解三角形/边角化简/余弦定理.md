# 余弦定理

## 适用场景

**适用**：等式含边的平方项（如 $a^2, b^2+c^2$）或明确给出三边一角关系；或正弦定理化简后出现 $\cos A$ 形式需进一步求角

**不适用**：纯角关系式（如 $\sin A + \sin B = \sin C$）无边参与；或仅含一次边且无角平方（如 $a+b=c$）

## 标准教学流程（步骤化）

1. 步骤1：审题定位——识别式中是否含 $a^2, b^2, c^2$ 或邻边对边组合（如 $b^2+c^2-a^2$）
2. 步骤2：选法决策——若含平方项或三边一角结构，立即选用余弦定理；若正弦化简后得 $\cos A$ 表达式，转入此法
3. 步骤3：构造辅助元素——将 $\cos A$ 写为 $\frac{b^2+c^2-a^2}{2bc}$，分子分母同乘或同除以相同因子凑标准形式
4. 步骤4：逻辑闭环——化简得 $\cos A = k$ 后，结合 $A\in(0,\pi)$ 唯一确定角 $A$

## 关键技巧清单

- ✅ 余弦定理口诀：'邻边平方和减对边方，除以二倍邻边积；知三边求角用它，知两边及夹角求第三边也用它'
- ✅ 逆用技巧：由 $b^2 + c^2 - a^2 = \sqrt{3}bc$ 直接得 $\cos A = \frac{\sqrt{3}}{2} \Rightarrow A = 30^\circ$
- ✅ 分母统一法：当式子含 $bc, ab, ac$ 等不同分母时，通分后分子必为余弦定理分子形式（如 $a^2+b^2-c^2$）

## 核心公式

- $\cos A = \frac{b^2 + c^2 - a^2}{2bc}$
- $\cos B = \frac{a^2 + c^2 - b^2}{2ac}$
- $\cos C = \frac{a^2 + b^2 - c^2}{2ab}$

## 常见易错点

- ❌ 余弦定理公式记错：写成 $\cos A = \frac{a^2+b^2-c^2}{2ab}$（邻边错配）→ 全题0分
- ❌ 忽略角范围：由 $\cos C = \frac{1}{2}$ 得 $C = 60^\circ$ 或 $300^\circ$，未限定 $C\in(0,\pi)$ → 扣1分
- ❌ 计算符号错误：$b^2 + c^2 - a^2$ 中误为 $b^2 - c^2 - a^2$ → 过程分全失

## 评分要点（高考阅卷标准）

- 评分点1（余弦定理选择依据）：指出含边平方项或三边一角 → 1分
- 评分点2（公式正确书写）：写出 $\cos A = \frac{b^2+c^2-a^2}{2bc}$ 等任一标准式 → 2分
- 评分点3（代入化简）：正确代入数值并化简至 $\cos A = k$ 形式 → 2分
- 评分点4（角唯一确定）：写出 $A = \arccos k$ 且说明 $A\in(0,\pi)$ → 1分
