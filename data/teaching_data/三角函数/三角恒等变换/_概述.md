# 三角恒等变换

**难度**: 易

## 1. 常见出题形式

- 直接应用两角和差公式计算特殊角三角函数值（如cos75°）
- 逆用公式化简含sin/cos和差的代数式
- 结合诱导公式处理非标准角（如sin(α-β)中β为钝角）
- 用二倍角公式化简$\sin2\alpha$、$\cos2\alpha$、$\tan2\alpha$
- 含$\sin\alpha\cos\alpha$、$\cos^2\alpha$、$\sin^2\alpha$的齐次式化简
- 含参数的二倍角方程（如$6\cos^2\alpha-8\cos\alpha-8=0$）
- 已知 $a\sin\alpha + b\cos\alpha = c$，求 $\tan\alpha$ 或 $\sin\alpha, \cos\alpha$ 的值
- 已知 $\sin\alpha \pm \cos\alpha = m$，求 $\sin2\alpha$、$\sin\alpha$ 或 $\cos\alpha$
- 已知含 $\sin\alpha, \cos\alpha$ 的分式等式（如 $\frac{\sin\alpha - \cos\alpha}{\sin\alpha + \cos\alpha} = k$），求 $\tan\alpha$ 或三角函数值
- 已知 $\sin\alpha + \cos\beta = p$, $\cos\alpha + \sin\beta = q$，求 $\sin(\alpha+\beta)$
- 已知 $\cos(\alpha-\beta), \sin(\frac{\alpha}{2}-\beta)$，求 $\sin(\frac{\alpha}{2}+\beta)$
- 已知 $\cos\alpha - \frac{1}{2}\cos\beta = m$, $\sin\alpha - \frac{1}{2}\sin\beta = n$，求 $\cos(\alpha-\beta)$
- 含sinα±cosα与1±sin2α的化简求值（如：√(1−2sin20°cos20°)）
- 含A sinθ + B cosθ的化简或求值（如：√3 cos20° ± 3 sin20°）
- 多角混杂型（如：已知sin(β−α)=1/6, sin(α+2β)=1/2，求cos2(α+β)）

## 2. 推荐解题方法及适用场景

| 方法 | 适用场景 | 不适用场景 |
|--------|------------|--------------|
| **和差化积** | 题干出现sinα±sinβ、cosα±cosβ结构，或需将和差式转为积式简化时 | 题干为单一角的倍角/半角问题（如sin2α）时，应优先用二倍角公式 |
| **二倍角公式** | 题干含2α与α的混合表达式，或需降幂（如$\sin^2\alpha→\frac{1-\cos2\alpha}{2}$） | 纯和差角问题（如$\sin(\alpha+\beta)$）或需积化和差 |
| **对偶式法** | 当题干明确给出形如 $a\sin\theta + b\cos\theta = c$ 的单一方程，且未提供 $\sin^2\theta + \cos^2\theta = 1$ 直接联立条件时优先使用 | 当题目已直接给出 $\sin^2\theta + \cos^2\theta = 1$ 或可轻松导出另一独立方程（如 $\sin\theta - \cos\theta$）时，不推荐；或当 $a,b$ 含复杂根式/分数导致 $A^2+B^2=C^2+X^2$ 计算量反超时 |
| **切化弦+整体代换** | 当题干含 $\tan\alpha, \tan\beta$ 等正切比值，且目标式含 $\cos(\alpha\pm\beta)$ 或需消元时 | 当目标式为纯正切表达式（如 $\tan(\alpha+\beta)$）且已知两角正切值时，应直接用正切和角公式而非切化弦 |
| **找角关系+缩角法** | 当题干与目标式均含复杂角组合（如 $\alpha-2\beta$, $\frac{\alpha}{2}-\beta$），且给定角范围较宽泛时 | 当角范围已精确到单一象限（如 $\alpha\in(0,\frac{\pi}{4})$）且无需进一步缩小，或角关系明显为倍角/和差时 |
| **无脑找特征** | 题目中出现明显结构特征（如sin±cos、1±sin2α、1±cos2α、A sin+B cos、平方差、完全平方三项式）时优先使用 | 当所有角度均为非特殊角且无代数结构特征（如纯数值嵌套tan(arctan2+arctan3)）时不宜直接套用 |
| **凑齐次** | 分式结构中分子分母各项次数不一致（如含cos²θ、常数项、sin2θ），且题目给出tanθ值或可求tanθ时 | 当题目明确要求保留sin/cos形式（如证明恒等式）或给定条件为sinθ+cosθ值而非tanθ时 |
| **找角关系** | 题干含多个不同角度（如α, β, 2α+β, α−2β）且无直接运算路径时 | 当所有角度均为同一角的整数倍（如α, 2α, 4α）且可直接用二倍角迭代时 |
