# 通项放缩法

## 适用场景

**适用**：当aₙ含根式/复杂分式无法直接求和，但可放缩为等比/裂项/错位可求和形式时适用

**不适用**：放缩方向错误（如需证<却放大）或放缩后仍不可求和时

## 标准教学流程（步骤化）

1. 步骤1：审题定位——分析aₙ结构，寻找可放缩点（如√(x²+1) > x，1/(n²+1) < 1/n²）
2. 步骤2：选法决策——对比放缩目标：等比（q<1）、裂项（分母两因子）、错位（等差×等比）
3. 步骤3：构造辅助元素——实施放缩（如√(1+q²ⁿ) > qⁿ），确保方向与不等式一致
4. 步骤4：逻辑闭环——对放缩后数列求和，利用∑bₖ ≥ ∑aₖ完成证明

## 关键技巧清单

- ✅ 技巧1：放缩方向口诀——‘证<则放大分母/缩小分子；证>则反之’
- ✅ 技巧2：目标导向放缩——根据右侧形式反推：若右侧为等比和，则放缩为等比；若为裂项和，则放缩为裂项结构

## 核心公式

- $\sqrt{1 + q^{2n}} > q^n \quad (q>0)$
- $\frac{1}{n^2 + 1} < \frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}$

## 常见易错点

- ❌ 易错点1：方向错误——证∑aₙ < C却放大aₙ得∑bₙ > ∑aₙ，无法推出结论，扣3分
- ❌ 易错点2：放缩过度——如将1/√n放大为1/n，但∑1/n发散，失去意义，扣2分

## 评分要点（高考阅卷标准）

- 评分点1（合理放缩）：写出正确aₙ ≤ bₙ且∑bₙ可求 → 3分
- 评分点2（求和正确）：算出∑bₙ表达式 → 3分
- 评分点3（不等式链接）：明确写出∑aₙ ≤ ∑bₙ < C → 2分
