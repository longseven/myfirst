# 求通项公式

**难度**: 易-中档

## 1. 常见出题形式

- 已知等差数列中两项（如A₃+A₅=24）及前n项和（如S₆=48），求公差d或通项aₙ
- 已知递推关系含(-1)ⁿ（如aₙ₊₂ = aₙ₊₁ - aₙ 或 aₙ₊₂ + aₙ₊₁ = 3n-1），求aₙ表达式
- 已知aₙ与Sₙ混合关系（如Sₙ = (-1)ⁿaₙ + 2ⁿ⁻¹），且n≥2时aₙ = Sₙ - Sₙ₋₁，求aₙ
- 递推式含aₙ₊₁与aₙ的线性关系（如aₙ₊₁ = paₙ + q）
- 递推式含aₙ₊₁与aₙ的分式结构（如aₙ₊₁ = aₙ/(kaₙ + b)）
- 递推式含aₙ与Sₙ混搭（如Sₙ = f(aₙ)或含aₙ、Sₙ、n的复合等式）

## 2. 推荐解题方法及适用场景

| 方法 | 适用场景 | 不适用场景 |
|--------|------------|--------------|
| **待定系数法** | 当题干明确数列为等差/等比，且给出若干具体项值或和值，可设aₙ = A·n + B（等差）或aₙ = A·qⁿ⁻¹（等比）时优先使用 | 当数列类型未知、或递推关系非线性（如含aₙ²）、或含(-1)ⁿ导致奇偶分段时不可直接套用 |
| **累加法** | 当递推式为aₙ₊₁ - aₙ = f(n)（相邻项差为n的函数）或隔项差（如aₙ₊₂ - aₙ = c）时优先使用 | 当递推式为aₙ₊₁ + aₙ = f(n)（含加法）或含乘除运算时不可直接使用 |
| **累乘法** | 当递推式可化为aₙ₊₁ / aₙ = f(n)，且f(n)为可连乘函数（如有理式、多项式比）时 | 当aₙ可能为0（导致除零无定义）或f(n)含无法约简的复杂根式时 |
| **退一相减法** | 当递推式含aₙ与Sₙ混搭（如Sₙ = g(aₙ,n)或含aₙ₊₁,Sₙ₊₁的复合式）时 | 当式中无Sₙ（纯aₙ递推）或Sₙ已显式给出无需消元时 |
