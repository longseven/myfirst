# 证明不等式

**难度**: 中档-拔高

## 1. 常见出题形式

- 指对混合不等式（如e^x > lnx + 2）
- 含e^x与多项式的不等式（如e^x + 1/x > 2 − ln x + x^2 + x）
- 需加强放缩的不等式（如e^x > 1 + x + (x−1)^2）
- 极值点偏移类：已知f(x₁)=f(x₂)且x₁≠x₂，证x₁+x₂>2x₀或x₁x₂>1（x₀为极值点）
- 多变量对称不等式：含x₁,x₂的对称式需消元（如2023年吉林模拟斜率不等式）
- 含参恒成立转化：通过极值点偏移构造单变量函数证明
- 含eˣ与lnx的混合不等式（如eˣ > x+1, lnx ≤ x-1）
- 需构造同构函数的指幂对幂结构（如x·eˣ与y·lny）
- 利用切线放缩证明粗糙不等式（如eˣ ≥ x+1, lnx ≤ x-1）
- 不含参数的不等式证明（如：x>0时，e^x > x+1）
- 含参数且给定参数范围的不等式证明（如：a≥1时，ax²+x−1+e^x > 0）
- 连不等式证明（如：1 < \frac{\ln x}{x-1} < \frac{x}{x-1},\ x>1）

## 2. 推荐解题方法及适用场景

| 方法 | 适用场景 | 不适用场景 |
|--------|------------|--------------|
| **放缩法** | 不等式含e^x、lnx等超越函数，直接求导困难时；或需构造中间变量C使A<C<B时 | 不等式两侧均为多项式或可直接构造函数求最值时（此时应优先用构造函数法） |
| **比值代换** | 当题设含f(x₁)=f(x₂)且表达式可化为x₁/x₂形式（如e^{x₁}/e^{x₂}=x₁/x₂）时 | 当x₁,x₂无直接比例关系或函数非严格单调无法建立单射映射时 |
| **齐次消元** | 当目标不等式左右次数不同（如x₁+x₂>2为1次vs常数0次），但可通过取对数/乘1等操作凑成齐次式时 | 当函数含不可化简的非齐次项（如f(x)=eˣ+x²）且无自然对称结构时 |
| **构造函数** | 不等式两侧可变形为同一函数的不同自变量（如F(u) ≥ F(v)），且F单调性可判定时 | 当构造函数非单调且两自变量无法保证同属单调区间，或函数含多层嵌套难以求导时 |
| **直接构造函数求导** | 不等式不含参数，或变形后可消去所有参数；函数结构较简单（如仅含e^x、ln x、多项式中的单一类型） | 含对数与多项式/指数混杂（如\frac{\ln x}{x-1}），或含三角函数与指数复合（如e^x\cos x）时直接求导将导致高阶复杂分式 |
| **变换主元** | 不等式含参数a且题目明确给出a的取值范围（如a≥1或a≤2），且参数在表达式中仅出现一次且为线性形式（如a·x²） | 参数以非线性形式多次出现（如a²、e^a、ln a、a与a²共存），或参数范围未给出（属‘恒成立求参’范畴） |
