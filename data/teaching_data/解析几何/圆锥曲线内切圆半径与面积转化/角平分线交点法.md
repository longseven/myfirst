# 角平分线交点法

## 适用场景

**适用**：题干涉及内切圆圆心（内心）坐标、角度关系或需证明某点为内心

**不适用**：仅求半径而无角度/坐标信息时（计算冗余）

## 标准教学流程（步骤化）

1. 步骤1：审题定位——确认目标为内心I坐标或∠AIB等角度值
2. 步骤2：选法决策——当出现'三条角平分线交于一点'或'求∠AIC'时启用
3. 步骤3：构造辅助元素——作出∠A、∠B的角平分线，交点即为I；或利用角平分线定理求分点
4. 步骤4：逻辑闭环——写出角平分线方程或用定理$\frac{BD}{DC} = \frac{AB}{AC}$求比例

## 关键技巧清单

- ✅ 定理：角平分线定理——$\frac{BD}{DC} = \frac{AB}{AC}$（D在BC上）
- ✅ 性质：内心I到三边距离相等，且$I = \left(\frac{aA_x + bB_x + cC_x}{a+b+c}, \frac{aA_y + bB_y + cC_y}{a+b+c}\right)$

## 核心公式

- $\frac{BD}{DC} = \frac{AB}{AC}$
- $I = \left(\frac{aA_x + bB_x + cC_x}{a+b+c}, \frac{aA_y + bB_y + cC_y}{a+b+c}\right)$

## 常见易错点

- ❌ 角平分线定理误写为$\frac{BD}{DC} = \frac{AC}{AB}$→比例倒置（扣1分）
- ❌ 内心坐标公式漏乘边长权重a,b,c→坐标错误（扣2分）

## 评分要点（高考阅卷标准）

- 评分点1（正确应用角平分线定理列比例式 → 2分）
- 评分点2（求出内心坐标或角度值 → 2分）
- 评分点3（验证I到三边距离相等 → 1分）
