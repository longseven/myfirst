# 数列与递推

**难度**: 拔高

## 1. 常见出题形式

- 含(-1)ⁿ的递推式（如aₙ₊₂ = aₙ₊₁ - aₙ），求周期性或a₂₀₂₆
- aₙ与Sₙ混合递推（如Sₙ = (-1)ⁿaₙ + 2ⁿ⁻¹），利用aₙ = Sₙ - Sₙ₋₁（n≥2）求通项
- 双数列递推（如4aₙ₊₁ = 3aₙ - bₙ + 4, 4bₙ₊₁ = 3bₙ - aₙ - 4），通过aₙ±bₙ构造新数列
- 一阶非线性递推（如xₙ₊₁ = axₙ² − bxₙ）研究单调性与范围
- 迭代式单调性（如证{x₂ₙ}单调，需分析xₙ₊₂ − xₙ）
- 递推不等式证明（如|xₙ₊₁ − xₙ| ≤ (2/5)|xₙ − xₙ₋₁|）
- 含参数的递推式最值分析（如含m的aₙ表达式求max/min）
- 多层递推嵌套（如aₙ与bₙ互递推）
- 离散函数性质综合（单调性+最值+恒成立）

## 2. 推荐解题方法及适用场景

| 方法 | 适用场景 | 不适用场景 |
|--------|------------|--------------|
| **构造新数列** | 当递推式含多个数列（aₙ,bₙ）或aₙ与Sₙ混搭，且存在线性组合（如aₙ+bₙ, aₙ-bₙ）使新数列呈等差/等比时优先使用 | 当递推式为非线性（如aₙ₊₁ = aₙ²）或无法找到有效组合时不可用 |
| **迭代分析法** | 当递推式含平方、倒数等非线性项，需研究单调性/范围/不等式时适用 | 线性递推（如xₙ₊₁ = pxₙ + q）可用待定系数法直接求通项时 |
| **数学归纳法** | 当需证对所有n∈ℕ⁺成立的命题（如aₙ通项、不等式、整除性）且递推关系明确时 | 当命题依赖n的连续性（如极限）或递推无初值支撑时 |
