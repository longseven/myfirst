# 集合运算

**难度**: 易

## 1. 常见出题形式

- 数轴交并补：如$A = \{x \mid x^2 - 4 > 0\}, B = \{x \mid x < 3\}$，求$A \cap B$
- 含参集合关系：如$A = \{x \mid x > a\}, B = \{x \mid x > 2\}$，已知$A \subseteq B$，求$a$范围
- 新定义集合：如定义$A*B = \{x \mid x \in A \cup B \text{ 且 } x \notin A \cap B\}$，求$(A*B)*C$
- 判断给定描述能否构成集合（考查确定性）
- 含参集合为空集时求参数范围
- 已知子集关系（如B⊆A）求参数取值范围

## 2. 推荐解题方法及适用场景

| 方法 | 适用场景 | 不适用场景 |
|--------|------------|--------------|
| **数轴标根法** | 所有涉及实数集、区间表示的集合运算题，尤其适用于含不等式的集合 | 当集合为离散点集（如$\{1,2,3\}$）或抽象集合（无具体元素）时，数轴法不适用 |
