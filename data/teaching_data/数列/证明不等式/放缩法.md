# 放缩法

## 适用场景

**适用**：当需证aₙ < bₙ或Sₙ < C，且bₙ/C为易控上界（如等比、可裂项）时

**不适用**：当放缩方向错误（如需上界却放小）或放缩后仍无法控制时

## 标准教学流程（步骤化）

1. 步骤1：审题定位——明确目标不等式方向（上界/下界）及精度要求
2. 步骤2：选法决策——选择'等比放缩'（如1/2ⁿ）或'裂项放缩'（如1/n² < 1/[n(n−1)]）
3. 步骤3：构造辅助元素——将aₙ逐项放大为bₙ，确保∑bₙ可求且≤C
4. 步骤4：逻辑闭环——写出aₙ < bₙ → ∑aₙ < ∑bₙ ≤ C，并验证首项成立

## 关键技巧清单

- ✅ 经典放缩：$\frac{1}{n^2} < \frac{1}{n(n-1)} = \frac{1}{n-1} - \frac{1}{n}\ (n>1)$
- ✅ 指数放缩：$\frac{1}{2^n} < \frac{1}{n^2}\ (n≥4)$

## 核心公式

- $\sum_{k=1}^{n} \frac{1}{k^2} < 2$

## 常见易错点

- ❌ 放缩未验证n起点→n=1时1/[n(n−1)]无定义→扣1分
- ❌ 放缩后和仍发散→未达上界→全题0分

## 评分要点（高考阅卷标准）

- 评分点1（选择合理放缩模型）→ 1分
- 评分点2（严格证明aₙ < bₙ对所有n成立）→ 2分
- 评分点3（求出∑bₙ并证≤C）→ 2分
- 评分点4（结论完整表述）→ 1分
