# 边角互化法

## 适用场景

**适用**：题干给出纯边等式、纯角等式或混合等式，需通过正弦/余弦定理统一为边或角的形式进行判定

**不适用**：题干为几何位置关系（如中垂线、角平分线）且无显式数量关系时

## 标准教学流程（步骤化）

1. 步骤1：审题定位——识别等式类型（边式/角式/混合式），标记待判定的角或边
2. 步骤2：选法决策——若含sin/cos，优先用正弦定理化边；若含a²,b²,c²，优先用余弦定理化角
3. 步骤3：构造辅助元素——执行边角互化（如sinA=a/(2R)代入角式；或cosA=(b²+c²−a²)/(2bc)代入边式）
4. 步骤4：逻辑闭环——化简至标准形式（如a²+b²=c²→直角；a=b→等腰），结合三角形内角和验证合理性

## 关键技巧清单

- ✅ 技巧1：正弦定理消角：$\sin A : \sin B : \sin C = a : b : c$
- ✅ 技巧2：余弦定理判角：$\cos A > 0 \Leftrightarrow A < \frac{\pi}{2}$；$\cos A = 0 \Leftrightarrow A = \frac{\pi}{2}$

## 核心公式

- $\sin A = \frac{a}{2R}$
- $\cos A = \frac{b^2 + c^2 - a^2}{2bc}$
- $A + B + C = \pi$

## 常见易错点

- ❌ 易错点1：未注明三角形内角范围（如cosA=0推出A=90°但未排除A=270°）→ 扣1分
- ❌ 易错点2：对sin²A+sin²B=sin²C直接开方得sinA+sinB=sinC → 概念错误全扣

## 评分要点（高考阅卷标准）

- 评分点1（选择正确的互化路径）→ 2分
- 评分点2（完成代数化简并得到标准关系式）→ 3分
- 评分点3（准确写出三角形形状结论）→ 2分
- 评分点4（简要验证内角和或边长正性）→ 1分
