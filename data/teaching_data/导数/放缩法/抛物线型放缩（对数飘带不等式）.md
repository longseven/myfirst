# 抛物线型放缩（对数飘带不等式）

## 适用场景

**适用**：当不等式含ln x且自变量x与1有明确大小关系（x>1或0<x<1），需比直线切线更精确的二次精度时

**不适用**：当x=1附近但需更高阶精度（如三阶泰勒），或x远离1（如x→0⁺或x→+∞）导致分式失效时

## 标准教学流程（步骤化）

1. 步骤1：审题定位——识别ln x结构，判断x与1的大小关系（关键分界点）
2. 步骤2：选法决策——若直线切线（ln x ≤ x−1）放缩失败（中间值过小/过大），则启用抛物线型放缩
3. 步骤3：构造辅助不等式——x>1时用ln x ≤ 2(x−1)/(x+1)或ln x ≥ (1/2)(x−1/x)；0<x<1时取反向不等式
4. 步骤4：逻辑闭环——将ln x整体替换为对应分式，化简为纯代数不等式并完成证明

## 关键技巧清单

- ✅ 技巧1：'一分为二'口诀——x>1用下界≤上界，0<x<1用上界≥下界；两组不等式统一记为：\frac{1}{2}\left(x-\frac{1}{x}\right) \leq \ln x \leq \frac{2(x-1)}{x+1}（x>0,x≠1）
- ✅ 技巧2：'零点验证法'——构造g(x)=ln x − f(x)，求导得g'(x)为完全平方式→单调性确定→代入x=1得g(1)=0→符号由区间决定

## 核心公式

- $\ln x \geq \frac{1}{2}\left(x-\frac{1}{x}\right)$
- $\ln x \leq \frac{2(x-1)}{x+1}$
- $\ln x \leq x-1$
- $e^x \geq x+1$

## 常见易错点

- ❌ 易错点1：混淆x>1与0<x<1的不等号方向→直接套用同一不等式导致逻辑断裂→高考扣2分
- ❌ 易错点2：未先证明即使用抛物线不等式→阅卷按'无依据引用'处理→扣3分

## 评分要点（高考阅卷标准）

- 评分点1（如：正确写出g(x)=ln x − \frac{2(x-1)}{x+1} → 1分）
- 评分点2（如：求导得g'(x)=\frac{(x-1)^2}{x(x+1)^2}≥0 → 2分）
- 评分点3（如：说明g(1)=0且单调性→得出x>1时g(x)>0 → 2分）
