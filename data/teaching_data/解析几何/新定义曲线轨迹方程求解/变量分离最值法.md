# 变量分离最值法

## 适用场景

**适用**：已得轨迹方程，求单变量最值（如x₀最大值、y₀²最大值）且方程可解出该变量

**不适用**：方程无法显式解出目标变量（如高次混合项）时

## 标准教学流程（步骤化）

1. 步骤1：审题定位——明确目标变量（如y₀）及约束方程
2. 步骤2：选法决策——将方程视为y₀²关于x₀的函数，或反之
3. 步骤3：构造辅助元素——令$t = \sqrt{x_0^2 + 1}$（根式换元），转化为二次函数
4. 步骤4：逻辑闭环——求t范围→代入函数→求顶点值→回代得最值

## 关键技巧清单

- ✅ 换元口诀：'根式整体换元t，平方消根变整式；t范围由x范围定，二次函数顶点算'
- ✅ 公式：$y_0^2 = 4\sqrt{x_0^2 + 1} - (x_0^2 + 4)$ → 令$t = \sqrt{x_0^2 + 1}$，则$y_0^2 = -t^2 + 4t - 3$

## 核心公式

- $y_0^2 = -t^2 + 4t - 3$
- $t = \sqrt{x_0^2 + 1} \in [1,3]$

## 常见易错点

- ❌ 换元后忽略t ≥ 1（因根式≥0）→t范围错误（扣1分）
- ❌ 二次函数顶点横坐标计算错（如$-b/(2a)$漏负号）→最值错误（扣2分）

## 评分要点（高考阅卷标准）

- 评分点1（正确分离出目标变量表达式（如y₀²=...） → 2分）
- 评分点2（换元及t范围推导正确 → 2分）
- 评分点3（二次函数最值计算准确（如max y₀²=1 → y₀∈[−1,1]） → 2分）
