# 证明不等式

**难度**: 中档-拔高

## 1. 常见出题形式

- 证明等差数列中d>0 ⇔ S₄+S₆>2S₅（充要条件判断）
- 证明Sₙ/n也是等差数列，并求其公差
- 证明S_{2n}-S_n, S_{3n}-S_{2n}, ... 成等差数列
- 直接求和型——通项可裂项/错位，求和后证Sₙ < C（如∑1/[n(n+1)] < 1）
- 通项放缩型——通项复杂无法直接求和，放缩为可求和数列（如√(1+q²ⁿ) > qⁿ）
- 通项比较型——右侧为含n表达式F(n)，证∑aₖ < F(n)，转为证aₖ < bₖ且∑bₖ = F(n）
- 数列单调性判定（如证aₙ₊₁ > aₙ）
- 数列最值问题（如求使Sₙ最大的k）
- 参数恒成立问题（如m ≥ f(n)恒成立，求m范围）

## 2. 推荐解题方法及适用场景

| 方法 | 适用场景 | 不适用场景 |
|--------|------------|--------------|
| **代数恒等变形** | 当需证明含Sₙ的代数式恒成立（如Sₙ/n为等差），或需建立d与Sₙ关系时优先使用 | 当不等式含绝对值、根号或需极限思想时不可直接使用 |
| **直接求和法** | 当通项aₙ可直接裂项、错位或分组求和得到精确Sₙ表达式时适用 | 通项无法解析求和（如∑1/√n、∑sin(n)）或求和过程超纲时 |
| **通项放缩法** | 当aₙ含根式/复杂分式无法直接求和，但可放缩为等比/裂项/错位可求和形式时适用 | 放缩方向错误（如需证<却放大）或放缩后仍不可求和时 |
| **通项比较法** | 当不等式右侧为含n表达式F(n)（如2√n、n(n+1)/2）时，设F(n)=∑bₖ，证aₖ < bₖ | 右侧为常数C时（此时通项放缩更直接） |
| **放缩法** | 当需证aₙ < bₙ或Sₙ < C，且bₙ/C为易控上界（如等比、可裂项）时 | 当放缩方向错误（如需上界却放小）或放缩后仍无法控制时 |
