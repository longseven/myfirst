# 概率统计 · 分布列与期望

## 一、题型识别特征

**题干常见表述：**
- "求随机变量 X 的分布列和数学期望"
- "求...的概率分布"
- "求 E(X) 和 D(X)"

**常见场景：**
1. 有放回/不放回抽样
2. 比赛得分/胜负场次
3. 产品合格/次品数
4. 摸球/抽奖问题

---

## 二、解题五步法

### 第 1 步：确定随机变量 X 的所有可能取值

```
示例：从 5 个红球、3 个白球中任取 3 个，X 表示红球个数
X 的可能取值：0, 1, 2, 3
```

### 第 2 步：逐个计算每个取值的概率

**关键技巧：**
- 分子：符合条件的组合数
- 分母：总组合数
- 使用组合公式 C(n,m) = n!/(m!(n-m)!)

```
示例：P(X=2) = C(5,2)·C(3,1) / C(8,3)
            = 10×3 / 56
            = 15/28
```

### 第 3 步：写出分布列（表格形式）

| X | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| P | ? | ? | ? | ? |

**检验：所有概率之和必须等于 1**

### 第 4 步：计算数学期望 E(X)

**公式：E(X) = Σ[xᵢ·P(X=xᵢ)]**

```
E(X) = 0×P(0) + 1×P(1) + 2×P(2) + 3×P(3)
```

### 第 5 步：计算方差 D(X)（如需）

**公式：D(X) = E(X²) - [E(X)]²**

或

**公式：D(X) = Σ[(xᵢ-E(X))²·P(X=xᵢ)]**

## 三、常见分布模型

### 1. 超几何分布（不放回抽样）

**条件：** 总数 N，其中 M 个成功，抽取 n 个

**公式：** P(X=k) = C(M,k)·C(N-M,n-k) / C(N,n)

**期望：E(X) = n·(M/N)**

**方差：D(X) = n·(M/N)·(1-M/N)·(N-n)/(N-1)**

### 2. 二项分布（有放回抽样/n 重伯努利试验）

**记作：X ~ B(n, p)**

**公式：P(X=k) = C(n,k)·p^k·(1-p)^(n-k)**

**期望：E(X) = np**

**方差：D(X) = np(1-p)**

### 3. 特殊分布的记忆公式

| 分布 | 期望 | 方差 |
|------|------|------|
| 两点分布 B(1,p) | p | p(1-p) |
| 二项分布 B(n,p) | np | np(1-p) |
| 超几何分布 | n·(M/N) | n·(M/N)·(1-M/N)·(N-n)/(N-1) |

## 四、易错点警示

| 易错点 | 正确做法 |
|--------|----------|
| 分布列概率和不为 1 | 必须检验ΣP = 1，发现错误立即检查 |
| 混淆有放回与不放回 | 有放回→二项分布；不放回→超几何分布 |
| 期望公式记错 | E(X) 是"值×概率"求和，不是概率求和 |
| 方差计算漏平方 | D(X) = E(X²) - [E(X)]²，注意平方位置 |
| 组合数计算错误 | C(n,2)=n(n-1)/2，C(n,3)=n(n-1)(n-2)/6 |

## 五、高考命题趋势

1. **实际应用背景**：结合生产、生活情境命题
2. **多问综合**：第一问求概率，第二问求分布列和期望
3. **创新题型**：如"最佳策略选择"、"风险评估"等
4. **计算量控制**：数字设计通常可约分，避免复杂计算

---

## 六、教学建议

1. **建模意识**：读完题立即判断是哪种分布模型
2. **规范表格**：分布列必须画表格，X 在上 P 在下
3. **检验习惯**：算完分布列立即检验概率和
4. **特殊值法**：选择题可用特殊值快速验证
