# 求定点定值

**难度**: 中档-拔高

## 1. 常见出题形式

- 斜率之积k₁k₂为定值——如MP,MQ斜率乘积恒为−1/2
- 中点G与原点连线斜率k₀与直线斜率k之积为定值
- 动直线TQ恒过定点——如证明TQ过y轴上定点(0,−1)
- 椭圆焦点三角形中已知角度求离心率（如∠F₁PF₂=60°）
- 过原点直线与椭圆交于A,B，连AF₁,BF₁构成三角形，已知边长及cos值求离心率
- 以OF为半径作圆与椭圆交于A,B，已知tan∠ABF求离心率
- 含参直线系恒过定点（如直线x−y+m=0，无论m取何值均过定点）
- 动直线与圆相交于A,B，求证某量（如k_OA·k_OB、|OA|²+|OB|²）为定值
- 双曲线中焦点到渐近线距离为定值b
- 斜率之和/积为定值 → 直线AB恒过定点（如2017新课标Ⅰ卷）
- 两垂直弦中点连线恒过定点（如2024成都期中）
- 由定点引两条切线，切点弦恒过定点（如2023衡水期末）
- 切点弦恒过定点（如圆外点P在直线l上运动，切点弦AB恒过定点）
- 焦点三角形中某量为定值（如椭圆中∠F₁PF₂=90°时，|PF₁|·|PF₂|为定值）
- 阿氏圆中比例恒为定值（如单位圆上点N满足NA/NB为定值）
- 斜率积为定值（如K₁K₂为常数）
- 中点连线斜率为定值（如K_OG·K_L为定值）
- 动直线恒过定点（如TQ恒过y轴上定点）
- 阿基米德三角形中P、A、B三点坐标关系（P横坐标为AB中点横坐标）
- 阿基米德三角形面积公式（$S=\frac{|x_1-x_2|^3}{8p}$）
- 垂直焦点弦的弦长倒数和为定值
- 已知椭圆上两点A,B关于某直线对称，求该直线方程
- 已知向量关系AM=2MB（M为定点），求直线AB斜率
- 已知△APQ为等边三角形（A为椭圆顶点），求AQ斜率
- 含参直线系恒过定点问题（如：直线x−1+a(y+2)=0恒过定点）
- 圆系方程中公共弦所在直线恒过定点
- 动直线与定圆相切，切点弦（极线）恒过定点
- 斜率之和/积为定值 → 直线AB恒过定点（如2017新课标Ⅰ卷、2024成都期中）
- 动弦中点连线MN过定点（如2024成都期中、2023衡水期末）
- 由定点引两切线，切点弦恒过定点（如蒙日圆模型、2022唐山一模）
- 过曲线上定点P作两条斜率之和/积为定值的直线交曲线于A,B → AB恒过定点
- 四点共圆且在圆锥曲线上 → 某两弦斜率之和为0
- 极点P在定直线上运动 → 其对应极线恒过定点（或反之）

## 2. 推荐解题方法及适用场景

| 方法 | 适用场景 | 不适用场景 |
|--------|------------|--------------|
| **设点法** | 当定点/定值由动点P,Q坐标决定，且P,Q为直线与曲线交点时 | 当定点由纯几何构造（如垂心、外心）决定且无坐标关联时 |
| **焦点三角形定义法** | 题目直接给出椭圆上点P与两焦点F₁,F₂构成的三角形（即焦点三角形），且已知其角度或边长比例时 | 当仅连一个焦点（如只连AF₁未连BF₁）时，需先补全另一焦点连线，否则无法使用定义 |
| **参数分离法** | 直线方程含单参数（如m,k），需证明其恒过定点 | 含多参数（如m,n）或参数在分母/指数位置导致无法线性分离 |
| **联立韦达** | 题干明确给出直线与圆锥曲线相交、含斜率和/积条件、参数可消且无高次耦合时 | 当直线斜率不存在或需分类讨论、或存在多层嵌套关系（如P→A→C→Q→R）且参数难统一消去时 |
| **先猜后证** | 图形具对称性（如关于x/y轴对称）、或存在特殊位置（如弦与坐标轴重合）、或常规联立计算量过大时 | 当图形无明显对称轴、且所有点均非特殊位置（如焦点不在坐标轴上）时 |
| **改写法则** | 求圆锥曲线（圆/椭圆）上点P(x₀,y₀)处切线，或圆外点P引切线的切点弦方程时 | 双曲线/抛物线切线（需联立判别式）或非标准方程未化简时 |
| **垂直平分线翻译法** | 条件含'中点'、'对称'、'等腰'、'垂直平分线'等几何描述 | 条件为纯代数关系（如x₁+x₂=常数）且无几何语义时，应优先用韦达定理 |
| **极点极线** | 题干出现‘过定点作两直线交曲线于四点，连线交点轨迹’或‘证明某线恒过定点’且图形含‘叉形’（两直线四交点）结构时 | 当无叉形结构或定点不在曲线外部/内部典型位置（如焦点、顶点）时，强行套用易出错 |
