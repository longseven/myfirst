# 图解法

## 适用场景

**适用**：单绝对值不等式另一侧为非负常数（如 $|x-1|>2$）时

**不适用**：当另一侧含变量或为负数时

## 标准教学流程（步骤化）

1. 步骤1：审题定位——确认形式为 $|x-a|>c$ 或 $|x-a|<c$（$c\ge0$）
2. 步骤2：选法决策——若 $c\ge0$，直接用数轴距离定义
3. 步骤3：构造辅助元素——在数轴标出 $a$ 点；$|x-a|>c$ 表示 $x$ 到 $a$ 距离大于 $c$，即 $x<a-c$ 或 $x>a+c$
4. 步骤4：逻辑闭环——写出解集，注意 $c=0$ 时 $|x-a|>0$ 解为 $x\ne a$

## 关键技巧清单

- ✅ 技巧1：'距离模型'——$|x-a|$ 是 $x$ 到 $a$ 的距离，$|x-a|>c$ 即距离超限的两侧区域
- ✅ 技巧2：'等号处理'——$|x-a|\ge c$ 包含端点 $a\pm c$（实心），$|x-a|>c$ 不含（空心）

## 核心公式

- $|x-a| < c \iff a-c < x < a+c$
- $|x-a| > c \iff x < a-c \text{ 或 } x > a+c$

## 常见易错点

- ❌ 易错点1：混淆 $|x-a|>c$ 与 $|x-a|<c$ 的区域（内外颠倒）→高考扣2分
- ❌ 易错点2：$c<0$ 时仍强行解（如 $|x-1|>-2$ 错解为 $x<-1$ 或 $x>3$）→高考扣1分

## 评分要点（高考阅卷标准）

- 评分点1（正确理解距离含义 → 2分）
- 评分点2（端点取舍正确 → 1分）
- 评分点3（解集区间书写规范 → 2分）
