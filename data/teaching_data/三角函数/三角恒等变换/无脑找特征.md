# 无脑找特征

## 适用场景

**适用**：题目中出现明显结构特征（如sin±cos、1±sin2α、1±cos2α、A sin+B cos、平方差、完全平方三项式）时优先使用

**不适用**：当所有角度均为非特殊角且无代数结构特征（如纯数值嵌套tan(arctan2+arctan3)）时不宜直接套用

## 标准教学流程（步骤化）

1. 步骤1：审题定位——扫描题干中所有代数结构：是否含sin±cos？是否含1±sin2α或1±cos2α？是否含A sin+B cos？是否含平方差/完全平方三项？
2. 步骤2：选法决策——根据最高频特征匹配公式：sin±cos→联想到(sinx±cosx)²=1±sin2x；1±cos2α→立即写为2sin²α或2cos²α；A sin+B cos→提√(A²+B²)准备辅助角
3. 步骤3：构造辅助元素——对1±sin2α补全sin²+cos²=1；对A sin+B cos提取公因式后配凑特殊角（如√3/2→cos30°, 1/2→sin30°）；对多角混杂式设中间变量（如令β=α+γ）
4. 步骤4：逻辑闭环——完成降次/升角/合并后，检查最终表达式是否与所求目标形式一致（如求tan(α+π/4)则必须保留tanα或转化为tanα表达式）

## 关键技巧清单

- ✅ 技巧1：(sinx±cosx)² = 1±sin2x（口诀：'正负对应，符号同向'）
- ✅ 技巧2：1±cos2α = 2sin²α 或 2cos²α（口诀：'1加cos降余弦方，1减cos降正弦方'）
- ✅ 技巧3：A sinθ + B cosθ = √(A²+B²) sin(θ+φ)，其中tanφ = B/A（口诀：'提根号，sin打头，φ由B比A定'）

## 核心公式

- $(\sin x \pm \cos x)^2 = 1 \pm \sin 2x$
- $1 \pm \cos 2\alpha = 2\sin^2\alpha$ 或 $2\cos^2\alpha$
- $A\sin\theta + B\cos\theta = \sqrt{A^2+B^2}\sin(\theta+\varphi)$

## 常见易错点

- ❌ 易错点1：开方未加绝对值——如√(sin20°−cos20°)²直接写sin20°−cos20°，忽略20°<45°⇒cos20°>sin20°，正确应为|sin20°−cos20°|=cos20°−sin20°，漏写绝对值导致符号错误→高考扣1分
- ❌ 易错点2：降次升角后未验证角度范围——如将sin²20°→(1−cos40°)/2后，继续处理sin80°时未意识到80°=2×40°而强行拆为120°−40°，引入冗余角→增加计算量且易出错→高考扣2分

## 评分要点（高考阅卷标准）

- 评分点1（结构识别）：正确识别1−2sin20°cos20°为(sin20°−cos20°)² → 1分
- 评分点2（绝对值处理）：写出|sin20°−cos20°|并判断cos20°>sin20°得cos20°−sin20° → 2分
- 评分点3（辅助角实施）：提取√( (√3)²+3² )=2√3并配出sin60°/cos60° → 2分
- 评分点4（诱导公式应用）：将sin(π/2−4β)正确转化为cos4β → 1分
