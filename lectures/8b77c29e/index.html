对于多项式函数，我们用求导法判断单调性。先求导数：f'(x) = 3x² - 3。

$$f'(x) = 3x^2 - 3$$
Step 3

把导数因式分解：f'(x) = 3(x² - 1) = 3(x+1)(x-1)。令导数为零，得到两个零点 x = -1 和 x = 1。

$$f'(x) = 3(x+1)(x-1) = 0$$
$$x_1 = -1, \quad x_2 = 1$$

根据导数符号，我们用三个区间来分析单调性。在数轴上标出两个零点 -1 和 1。
