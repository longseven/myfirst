# 圆锥轴截面法

## 适用场景

**适用**：当三棱锥为正棱锥（顶点投影为底面中心）时，其外接球等价于对应圆锥外接球

**不适用**：当顶点投影偏离底面中心（如斜棱锥）或底面非正多边形时

## 标准教学流程（步骤化）

1. 步骤1：审题定位——确认‘正棱锥’定义：顶点在底面中心垂线上，底面为正多边形
2. 步骤2：选法决策——取底面外接圆半径r（正n边形：$r = \frac{a}{2\sin(\pi/n)}$）与锥高h
3. 步骤3：构造辅助元素——作轴截面（过顶点与底面中心的平面），得等腰三角形；球心O在轴上，设OO' = x（O'为底面中心）
4. 步骤4：逻辑闭环——列方程$R^2 = x^2 + r^2 = (h - x)^2$，解得$x = \frac{h^2 - r^2}{2h}$，代入得$R = \frac{h^2 + r^2}{2h}$

## 关键技巧清单

- ✅ 正棱锥外接球公式：$R = \frac{h^2 + r^2}{2h}$（h为高，r为底面外接圆半径）
- ✅ 正三角形特例：边长a，则$r = \frac{a}{\sqrt{3}}$；正方形边长a，则$r = \frac{a}{\sqrt{2}}$

## 核心公式

- $R = \frac{h^2 + r^2}{2h}$
- $r = \frac{a}{2\sin(\pi/n)}$

## 常见易错点

- ❌ 将底面中心误认为重心（正三角形重合，但正五边形不重合）→ r计算错误 → 扣2分
- ❌ 未区分h（锥高）与侧棱长l，混淆代入 → 公式失效，扣3分

## 评分要点（高考阅卷标准）

- 评分点1（如：正确求出底面外接圆半径r → 2分）
- 评分点2（如：正确建立$R^2 = x^2 + r^2 = (h - x)^2$方程 → 2分）
- 评分点3（如：解出R并化简 → 1分）
