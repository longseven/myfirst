# 排列组合·计数问题

## 一、题型识别特征

**题干关键词：**
- "共有多少种不同的..."
- "有多少种排法/选法/分配方法"
- "满足条件的...有多少个"

**常见场景：**
1. 排队站位问题
2. 数字组成问题（如用 1,2,3,4 组成四位数）
3. 选人分配问题
4. 涂色问题

---

## 二、两大基本原理

### 1. 分类加法计数原理

**特征：** "完成一件事有几类方法，每类方法都能独立完成这件事"

**公式：** N = m₁ + m₂ + ... + mₙ

**示例：** 从 A 地到 B 地，可以坐火车（3 班）、汽车（2 班）、飞机（1 班），共有 3+2+1=6 种走法

### 2. 分步乘法计数原理

**特征：** "完成一件事需要分成 n 个步骤，每步都不能独立完成"

**公式：** N = m₁ × m₂ × ... × mₙ

**示例：** 从 A 地到 C 地需在 B 地中转，A→B 有 3 条路，B→C 有 2 条路，共有 3×2=6 种走法

## 三、排列与组合

### 1. 排列（有序）

**定义：** 从 n 个不同元素中取出 m 个元素，按照一定顺序排成一列

**公式：** A(n,m) = n!/(n-m)!

**特征：** 交换位置后结果不同

**示例：** 3 个人排成一排，有 A(3,3) = 3! = 6 种排法

### 2. 组合（无序）

**定义：** 从 n 个不同元素中取出 m 个元素，不管顺序并成一组

**公式：** C(n,m) = n!/[m!(n-m)!]

**特征：** 交换位置后结果相同

**示例：** 从 5 人中选 3 人当代表，有 C(5,3) = 10 种选法

---

## 四、常用解题方法

### 1. 捆绑法（相邻问题）

**适用：** 某几个元素必须相邻

**方法：** 把必须相邻的元素视为一个整体，再与其他元素排列

**示例：** 3 男 3 女排队，要求女生相邻，有 A(4,4)×A(3,3) = 144 种

### 2. 插空法（不相邻问题）

**适用：** 某几个元素不能相邻

**方法：** 先排其他元素，再把不相邻的元素插入空隙

**示例：** 3 男 3 女排队，要求女生不相邻，先排男生 A(3,3)，再插空 A(4,3)，共 144 种

### 3. 优先法（特殊元素/位置）

**适用：** 有元素或位置有特殊要求

**方法：** 先满足特殊要求，再安排其他

**示例：** 6 人排队，甲必须站排头，有 A(5,5) = 120 种

### 4. 排除法（正难则反）

**适用：** 正面分类太复杂

**方法：** 总数 - 不符合条件的 = 符合条件的

**示例：** 用 0,1,2,3,4 组成无重复数字的三位数，至少有一个偶数的有多少个？
- 总数：A(5,3) - A(4,2) = 60 - 12 = 48（减去 0 开头的）
- 全奇数：A(3,3) = 6
- 答案：48 - 6 = 42 种

### 5. 分组分配法

**适用：** 平均分组或不平均分组

**公式：**
- 平均分到不同组：C(n,m)×C(n-m,m)×...
- 平均分到相同组：除以组数的阶乘

**示例：** 6 人平均分成 3 组，有 C(6,2)×C(4,2)×C(2,2)/3! = 15 种

## 五、易错点警示

| 易错点 | 正确做法 |
|--------|----------|
| 混淆排列组合 | 看是否与顺序有关：有关用 A，无关用 C |
| 重复计数 | 分类要互斥，分步要独立 |
| 漏掉特殊情况 | 如 0 不能排首位，甲必须站某位置等 |
| 平均分组忘除阶乘 | 分到相同组要除以组数！ |
| 捆绑法忘乘内部排列 | 捆绑后内部也要排列 |

---

## 六、解题步骤

```
1. 审题：明确是排列还是组合（看是否与顺序有关）
2. 分析：是否有特殊元素/位置，是否需分类/分步
3. 选择方法：捆绑法/插空法/优先法/排除法
4. 列式计算：写出表达式并计算
5. 检验：检查是否有重复或遗漏
```

---

## 七、高考命题趋势

1. **实际应用**：结合生活情境（如选课、排队、分配）
2. **综合考查**：与概率结合，先计数再求概率
3. **创新题型**：如"最佳方案选择"、"信息编码"等
4. **计算简化**：数字设计通常可约分，避免复杂运算

---

## 八、教学建议

1. **建模意识**：读完题立即判断是排列还是组合
2. **画图辅助**：排队问题画位置，分组问题画圈
3. **检验习惯**：用特殊值法或逆向验证
4. **分类训练**：按方法分类做题，形成肌肉记忆
