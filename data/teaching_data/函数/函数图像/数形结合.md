# 数形结合

## 适用场景

**适用**：当需直观理解函数行为（值域、零点、不等式解集）或题目含'图像'字眼时必须使用

**不适用**：当题目要求纯代数推导（如证明恒等式）或图像信息不足时，不适用

## 标准教学流程（步骤化）

1. 步骤1：审题定位——提取关键图像特征（渐近线、对称中心、周期、特殊点）
2. 步骤2：选法决策——若涉及交点、最值、单调区间等几何意义，立即启动数形结合
3. 步骤3：构造辅助元素——画坐标系→标渐近线→定象限→描特殊点（如y轴截距、顶点）→连光滑曲线
4. 步骤4：逻辑闭环——在图像上标注所求区间，读取y范围或交点横坐标和

## 关键技巧清单

- ✅ 技巧1：'对称中心坐标公式'——f(a+x)+f(b−x)=c ⇒ 对称中心为((a+b)/2, c/2)
- ✅ 技巧2：'周期图像复刻法'——以T为单位平移基础段，覆盖整个区间

## 核心公式

- $f(a+x) = f(b-x) \Rightarrow \text{对称轴 } x = \frac{a+b}{2}$
- $f(a+x) + f(b-x) = c \Rightarrow \text{对称中心 } \left(\frac{a+b}{2}, \frac{c}{2}\right)$

## 常见易错点

- ❌ 易错点1：混淆对称轴与对称中心——f(3−x)=f(9+x)误判为对称中心而非对称轴x=6→高考扣1分
- ❌ 易错点2：未验证交点对称性——两函数共对称中心时，误认为所有交点横坐标和为n·a，未排除重合点→高考扣1分

## 评分要点（高考阅卷标准）

- 评分点1（如：正确标出对称中心(2,0) → 1分）
- 评分点2（如：画出f(x)与y=x−2的图像并标出交点 → 2分）
- 评分点3（如：由图像指出交点关于(2,0)对称并得出Σx_i=2n → 2分）
