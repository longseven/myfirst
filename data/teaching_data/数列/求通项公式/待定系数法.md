# 待定系数法

## 适用场景

**适用**：当题干明确数列为等差/等比，且给出若干具体项值或和值，可设aₙ = A·n + B（等差）或aₙ = A·qⁿ⁻¹（等比）时优先使用

**不适用**：当数列类型未知、或递推关系非线性（如含aₙ²）、或含(-1)ⁿ导致奇偶分段时不可直接套用

## 标准教学流程（步骤化）

1. 步骤1：审题定位——确认数列类型（等差/等比/其他），提取已知项值或和值个数
2. 步骤2：选法决策——若类型明确且条件≥2个，设通项为一次/指数函数形式
3. 步骤3：构造辅助元素——将已知项代入设出的通项，列出关于系数的方程组
4. 步骤4：逻辑闭环——解方程组得系数，写出aₙ = ... 并验证n=1是否成立

## 关键技巧清单

- ✅ 技巧1：等差通项必为一次函数，aₙ = dn + (a₁-d)，其中d即公差（一次项系数）
- ✅ 技巧2：设aₙ = An + B后，公差d = A，首项a₁ = A + B

## 核心公式

- $a_n = a_1 + (n-1)d$
- $a_n = A n + B$

## 常见易错点

- ❌ 易错点1：设aₙ = a₁ + (n-1)d后未化简为标准一次式，导致后续系数识别错误→高考扣1分
- ❌ 易错点2：忽略n=1验证，当递推式仅对n≥2成立时，a₁需单独代入检验→高考扣1分

## 评分要点（高考阅卷标准）

- 评分点1（设通项形式正确 → 1分）
- 评分点2（列出正确方程组 → 2分）
- 评分点3（解出系数并写出aₙ → 2分）
