# 综合法（几何推理）

## 适用场景

**适用**：题干含中点、正方形、矩形、平行四边形等明显平面几何结构；面面垂直条件可直接利用（如"平面ABE⊥平面ABCD"）；图形具有对称性可减少计算

**不适用**：无中点、无对称性、无规则多边形；动点轨迹隐含圆/椭圆等非线性约束；需处理角度最值或动态范围时慎用

## 标准教学流程（步骤化）

1. **审题定位**：明确待证结论类型（线∥面、线⊥线、线⊥面、面⊥面、等距EA=EB），标记所有已知条件（中点、垂直、内接正方形、面面垂直等）。
2. **选法决策**：
   - 若待证"线∥面" → 看有无中点（中位线法）、平行四边形（对边法）、面面平行可用
   - 若待证"线⊥线"或"等距" → 看有无面面垂直条件（面面垂直性质法 / 投影对称法）
   - 若已知"面⊥面" → **核心操作**：找交线，在一平面内作交线的垂线 → 该垂线⊥另一平面
3. **构造辅助元素**：
   - *中位线法*：选面外一点，连该点与已知线段两端并延长交目标平面，证所得线段为三角形中位线
   - *面面垂直性质法*：设α⊥β，α∩β=l；在α内过点P作PH⊥l于H → PH⊥β。用此将面面垂直转为线面垂直
   - *投影对称法*（证EA=EB型）：设面ABE⊥面ABCD，AB为交线。在面ABE中作EH⊥AB于H。由面面垂直性质知EH⊥面ABCD。若ABCD有对称性使H为AB中点 → △EAB为等腰三角形 → EA=EB
   - *AF⊥DE型*：利用已知的垂直条件+面面垂直推出新的垂直关系，构建方程求解
4. **逻辑闭环**：写出完整推理链，三要素缺一不可：
   - 证线∥面：①线不在面内 ②线线平行（或面面平行推出） ③结论
   - 证线⊥面：①找两条相交线都与该线垂直 ②两线确实相交于一点且在平面内 ③结论
   - 证等距：将问题转化为等腰三角形或对称结构，最后回到几何结论

## 关键技巧清单

- ✅ **面面垂直核心定理**：若α⊥β，α∩β=l，过α内一点P作PH⊥l于H，则PH⊥β。这是将面面垂直转为线面垂直的唯一桥梁。
- ✅ **中位线定理**：三角形中位线平行第三边且等于一半（必须证两点为中点）。
- ✅ **等腰三角形判定**：底边中线 = 底边高 → 两腰相等。在面面垂直背景下，投影点落在底边中点即可。
- ✅ **内接正方形对称性**：正方形ABCD内接于圆O，则O为正方形中心，AB的中点在OA、OB连线上，各边中点关于O对称。
- ✅ **平行传递性**：a∥b, b∥c ⇒ a∥c（需共面或通过中间平面传递）。
- ✅ **棱柱性质**：侧面为平行四边形 → 对边平行且相等（高频用以证中点、平行）。
- ✅ **圆台特有**：上下底面平行，母线等长；内接正方形各边与圆相切/相交有固定关系。

## 核心公式

- $\text{中位线定理：} DE \parallel BC \text{ 且 } DE = \frac{1}{2}BC$
- $\text{面面垂直性质：} \alpha\perp\beta,\ \alpha\cap\beta=l,\ PH\perp l,\ P\in\alpha \Rightarrow PH\perp\beta$
- $\text{平行四边形判定：} AB \parallel CD \text{ 且 } AB = CD \Rightarrow ABCD \text{ 为平行四边形}$
- $\text{线面垂直判定：} a\perp b,\ a\perp c,\ b\cap c = P,\ b,c\subset\alpha \Rightarrow a\perp\alpha$

## 常见易错点

- ❌ **忽略"线不在面内"前提**：证线面平行漏写"MN⊄α"（高考扣1分）。
- ❌ **面面垂直性质用错**：直接写"因为面⊥面所以线⊥面"而未指明"在一面内作交线的垂线"这个关键操作步骤，扣2分。
- ❌ **投影点位置未证明**：在证EA=EB时，直接说"E在AB中垂面上"而未证明EH⊥AB中H为AB中点。需利用ABCD内接正方形的对称性来证H为中点。
- ❌ **连辅助线后未验证所作线确在目标平面内**（如误将空间线当平面内线）。
- ❌ **"目测平行/垂直"代替证明**（如直接写"显然MN∥EC"或"显然EH⊥面ABCD"）。

## 评分要点（高考阅卷标准）

- **4分题**（如证EA=EB）：
  - 正确指出交线AB、在面ABE中作EH⊥AB → **1分**
  - 由面面垂直性质得EH⊥面ABCD → **1分**
  - 利用对称性证H为AB中点 → **1分**
  - 由EH为底边中线得EA=EB → **1分**
- **6分题**（如三棱柱证BC₁∥平面A₁EC）：
  - 正确选取辅助点及连线 → **1分**
  - 准确找出交点/中点 → **1分**
  - 严谨证明中位线（两点为中点，侧面平行四边形性质） → **2分**
  - 结论及位置关系说明（线不在面内+线线平行→线面平行） → **2分**
