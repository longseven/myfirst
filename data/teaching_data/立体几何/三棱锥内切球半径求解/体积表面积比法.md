# 体积表面积比法

## 适用场景

**适用**：适用于任意三棱锥（无需特殊位置关系），且题目可直接或间接求出体积V与总表面积S_表

**不适用**：当三棱锥退化（如四点共面）或表面积无法闭合计算时（如缺面数据）

## 标准教学流程（步骤化）

1. 步骤1：审题定位——确认是否为三棱锥，明确‘内切球’即球与四个面均相切
2. 步骤2：选法决策——判断能否计算V与S_表；若能，则必用r = 3V / S_表
3. 步骤3：构造辅助元素——无须辅助线；但需分面计算各三角形面积（海伦公式/向量叉积/底×高÷2）
4. 步骤4：逻辑闭环——写出r = \frac{3V}{S_{\text{表}}}，代入数值并化简

## 关键技巧清单

- ✅ 公式口诀：‘三倍体积除以全表’ → $r = \frac{3V}{S_{\text{表}}}$
- ✅ 表面积S_表 = S_{\triangle ABC} + S_{\triangle PAB} + S_{\triangle PBC} + S_{\triangle PCA}$

## 核心公式

- $r = \frac{3V}{S_{\text{表}}}$
- $S_{\text{表}} = \sum S_{\text{面}}$

## 常见易错点

- ❌ 混淆内切球与内切圆：对三棱锥误用三角形内切圆公式$r = \frac{2S}{a+b+c}$ → 高考扣2分
- ❌ 漏算某一面面积（尤其隐含底面或侧面）→ 导致S_表错误，全题0分

## 评分要点（高考阅卷标准）

- 评分点1（如：正确写出体积公式并代入 → 1分）
- 评分点2（如：完整计算四个面面积并求和 → 2分）
- 评分点3（如：代入$r = \frac{3V}{S_{\text{表}}}$并化简得最终结果 → 2分）
